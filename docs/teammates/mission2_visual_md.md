# แผนการเรียนรู้ วัตถุประสงค์ที่ 2 — เส้นทาง “ดูวิดีโอ” (ฉบับปรับแก้)
> **สถานะ:** ฉบับปรับเกณฑ์ผ่านและ Feedback — 16 ตุลาคม 2569  
> **เรื่อง:** ระบบชื่อโดเมน  
> **วัตถุประสงค์ที่ 2:** **อธิบายส่วนประกอบและลำดับของชื่อโดเมนได้**  
> **เส้นทาง:** เข้าด่าน → รับภารกิจ → ดูคลิปสถานการณ์ → ตอบโดม 2 คำถาม → AI คำนวณคะแนนและให้ Feedback ตามระดับ → **คะแนนรวมมากกว่า 60% ผ่านทันที** → ไปวัตถุประสงค์ที่ 3  
> **ตัดออก:** ภารกิจภาพหลังคลิป และ D&D ในเส้นทาง “ดู” ของวัตถุประสงค์นี้

## 0. ข้อตกลงเรื่องคลิปที่ต้องยึดเป็นหลัก

**วิดีโอที่นักเรียนดูจริงจะไม่มีตัวอักษรหรือตัวเลขใด ๆ บนภาพเลย** ไม่ใช่แค่ห้าม AI สร้างข้อความผิดเท่านั้น แต่ **ไม่ต้องนำตัวอักษรหรือเลขมาใส่ทับในขั้นตัดต่อด้วย** ตามแนวทางที่ผู้ผลิตกำหนด
- ไม่มีคำว่า Subdomain, SLD, Second-Level Domain, TLD, Top-Level Domain, Root แสดงบนจอ
- ไม่มีชื่อเว็บไซต์ เช่น shop.khanombanyai.com หรือนามสกุล .com, .th ปรากฏเป็นตัวอักษรบนจอ
- ไม่มีป้ายร้านที่มีตัวหนังสือ ไม่มีข้อความบนโทรศัพท์/คอมพิวเตอร์ ไม่มีซับไตเติล ไม่มีกราฟิกตัวอักษรหรือเลข
- มีเพียง **ตัวละคร ภาพสถานการณ์ ภาพจำลองกระบวนการที่ใช้อุปกรณ์/บล็อกสี/ไอคอน/ลูกศร และบทพูดภาษาไทย (เสียง)**
- ในคลิป **ไม่มีโดม**; โดมเป็นผู้ช่วย AI บนหน้าระบบหลังดูคลิปเท่านั้น
- ผู้ผลิตเป็นผู้ตัดต่อคลิปเอง จึงสามารถใช้ภาพแอนิเมชันจาก Google Flow มาประกอบเสียงและลำดับเหตุการณ์ โดยไม่จำเป็นต้องพึ่งข้อความในวิดีโอ

**ห้ามให้โดมถามว่าตัวละครพิมพ์ชื่อเว็บไซต์ว่าอะไร บล็อกสีเขียนคำว่าอะไร นามสกุลเว็บสะกดอย่างไร หรือเห็นคำว่า TLD/SLD/Subdomain ตรงไหน** เพราะนักเรียนไม่เคยเห็นตัวอักษรเหล่านั้นในวิดีโอ

**หมายเหตุด้านความถูกต้อง:** เมื่อแสดงการทำงานและลำดับชั้นของโดเมนด้วยภาพ ต้องสื่อทิศทางให้ถูกต้องว่า **ชื่อโดเมนประกอบด้วยส่วนย่อย 3 ส่วน (ขวาสุดคือระดับบนสุด/กลุ่มประเภท -> ตรงกลางคือระดับที่สอง/ชื่อหลักของร้าน -> ซ้ายสุดคือระดับย่อย/บริการย่อย) และคอมพิวเตอร์จะอ่านลำดับความสำคัญจากขวาไปซ้ายเสมอ** (ใช้บล็อกสี ไอคอน และลูกศรแทนตัวอักษรทั้งหมด)

## 1. เป้าหมายของการเรียนรู้

เมื่อนักเรียนดูคลิปและตอบโดมเสร็จ ต้องทำได้เพียงสองเรื่องตามวัตถุประสงค์ ไม่ต้องอธิบายรายละเอียดโครงสร้างเครือข่ายเชิงลึก

| ตัวชี้วัด | สิ่งที่นักเรียนบอกได้ | ยังไม่ต้องวัดในด่านนี้ |
|---|---|---|
| OBJ2-A — ส่วนประกอบของชื่อโดเมน | บอกได้ว่าชื่อโดเมนแบ่งเป็นส่วนย่อยที่มีหน้าที่ต่างกัน ได้แก่ **ส่วนนามสกุล/บอกประเภทกลุ่มใหญ่ (ขวาสุด), ส่วนชื่อหลักของเว็บไซต์/ชื่อร้าน (ตรงกลาง), และส่วนบริการย่อย/หน้าย่อย (ซ้ายสุด)** | กฎเกณฑ์การตั้งชื่อเชิงเทคนิค (จำนวนตัวอักษร, อักขระพิเศษ), เงื่อนไขเอกสารในการจดทะเบียนแต่ละนามสกุล (อยู่ในด่าน 3) |
| OBJ2-B — ลำดับของชื่อโดเมน | อธิบายได้ว่าระบบโดเมนจัดเรียงเป็นลำดับชั้น และต้องอ่านหรือพิจารณาไล่ลำดับความสำคัญจาก **ขวาไปซ้าย** (จากกลุ่มใหญ่ระดับบนสุด มายังชื่อเฉพาะ และส่วนบริการย่อย) | โครงสร้าง DNS Tree ระดับ Root Server เชิงลึก, กระบวนการ Recursive/Iterative Query, การตั้งค่า Subdomain ในเซิร์ฟเวอร์จริง |

เกณฑ์ต้องพิจารณา **ความหมาย** ไม่ใช่บังคับให้ใช้คำศัพท์เทคนิคภาษาอังกฤษ (TLD, SLD, Subdomain) เป๊ะ ๆ นักเรียนอาจพูดว่า “แบ่งเป็น 3 ส่วน คือส่วนบอกประเภทเว็บ ส่วนชื่อร้าน และส่วนหน้าบริการย่อย” หรือ “ต้องอ่านจากขวาไปซ้าย เริ่มจากกลุ่มใหญ่สุดมาก่อน” ก็สามารถเป็นหลักฐานความเข้าใจได้ **การผ่านใช้คะแนนรวมมากกว่า 60%** จึงไม่บังคับให้คำตอบสมบูรณ์ทุกประเด็น แต่ต้องให้ Feedback ชัดเจนในส่วนที่ยังขาด

    ## 3. รายละเอียดหน้าจอในเส้นทางมือถือ

### หน้าจอ 0 — แผนภารกิจ
**สิ่งที่แสดง:** ชื่อหน่วย `ระบบชื่อโดเมน` การ์ด `ด่านที่ 2: ส่วนประกอบและลำดับของชื่อโดเมน` รูปแบบการเรียนรู้ `ดูวิดีโอ` สถานะ `ยังไม่เริ่ม/กำลังเรียน/ผ่านแล้ว` และปุ่ม `เข้าสู่ด่าน`  
**นักเรียนทำ:** แตะ `เข้าสู่ด่าน` -> หน้ารับภารกิจ

### หน้าจอ 1 — รับภารกิจ ก่อนดูคลิป
**องค์ประกอบ:**
- หัวข้อ: **ภารกิจที่ 2 — จัดลำดับชื่อเว็บเข้าหน้าสั่งขนมร้านบ้านยาย**
- ภาพปกนิ่ง: มีน ลูกค้า และคุณยายในร้านขนม กำลังดูหน้าจอโน้ตบุ๊กด้วยกัน (ภาพปกใน UI ใช้ข้อความได้ตามการออกแบบเว็บ แต่ไม่ใช่ข้อความในคลิป)
- สถานการณ์: **“ลูกค้าต้องการเข้าหน้าสั่งขนมออนไลน์ของร้านขนมบ้านยาย แต่สับสนเพราะชื่อเว็บไซต์มีหลายส่วนประกอบต่อกันจนเรียงลำดับไม่ถูก มีนจึงเข้ามาช่วยอธิบายว่าชื่อเว็บไซต์แบ่งเป็นกี่ส่วน และต้องเรียงลำดับจากทิศทางไหน”**
- คำแนะนำแบบง่าย: **“ดูเรื่องราวให้จบ แล้วตอบคำถามโดม 2 ข้อด้วยคำของตนเอง”**
- ปุ่มหลัก: `เริ่มดูวิดีโอ`
- ปุ่มรอง: `กลับแผนภารกิจ`

**ข้อควรระวัง:** ไม่เกริ่นว่าต้องจำตัวสะกดชื่อเว็บไซต์ภาษาอังกฤษหรือจำคำย่อใด ๆ บนจอ เพราะข้อมูลประเภทนั้นไม่ได้ปรากฏบนหน้าวิดีโอ

### หน้าจอ 2 — ดูคลิปสถานการณ์
**องค์ประกอบเว็บ:** วิดีโอแนวนอน 16:9, ปุ่มเล่น/หยุด, เล่นซ้ำ, ย้อนดู, ระดับเสียง, ตัวบอกความคืบหน้า *ใน UI เว็บภายนอกตัวคลิป*, ปุ่ม `คุยกับโดม` ซึ่งปลดล็อกเมื่อรับชมครบ  
**คลิปเอง:** แสดงภาพล้วน ๆ พร้อมเสียงบทสนทนา ไม่มีข้อความหรือตัวเลขในเฟรม ไม่ใส่ซับในวิดีโอ ไม่ใส่ตัวอักษรชื่อเว็บไซต์ในกราฟิก  
**สิ่งที่นักเรียนทำ:** ดูเหตุการณ์ -> อาจย้อนดูเอง -> เมื่อดูจบแตะ `คุยกับโดม`

#### 3.2.1 เหตุการณ์ของคลิป (ฉบับเล่าเรื่องง่าย)
> ใช้ **มีน ลูกค้า และยายเท่าที่จำเป็น**; ห้ามมีโดมในคลิป **บทพูดทั้งหมดเป็นเสียงพูด ไม่แสดงเป็นข้อความในภาพ**

| ช่วง/ฉาก | ภาพที่เห็น (ไม่มีตัวอักษรหรือตัวเลข) | บทพูดตัวอย่าง / เนื้อหาที่ได้ยิน | สิ่งที่นักเรียนควรเข้าใจ |
|---|---|---|---|
| 1. เกิดปัญหาสับสนลำดับ | ลูกค้าถือมือถือทำหน้างง ชี้ให้ยายและมีนดู บนจอมือถือแสดงบล็อกไอคอน 3 สีที่วางสลับตำแหน่งกันมั่วและมีเครื่องหมายตกใจ | ลูกค้า: **“หนูจะเข้าหน้าสั่งขนมออนไลน์ของร้าน แต่ชื่อเว็บมีหลายส่วนมาก เรียงไม่ถูกเลยเปิดไม่ได้ค่ะ”** | ชื่อเว็บไซต์มีหลายส่วนประกอบ หากเรียงลำดับผิดจะเข้าใช้งานไม่ถูกหน้า |
| 2. มีนเข้ามาช่วยแยกส่วน | มีนยิ้มและเปิดโน้ตบุ๊ก บนหน้าจอแสดงบล็อกสี 3 บล็อก (เขียว ฟ้า ส้ม) ค่อย ๆ แยกออกจากกันโดยมีจุดคั่นตรงกลางระหว่างบล็อก | มีน: **“ไม่ยากเลยค่ะ ชื่อโดเมนจะถูกแบ่งออกเป็นส่วนย่อย ๆ คั่นด้วยจุด ซึ่งแต่ละส่วนมีหน้าที่ต่างกันค่ะ”** | ชื่อโดเมนไม่ได้เป็นก้อนเดียว แต่แบ่งเป็นส่วนย่อย ๆ คั่นด้วยจุด |
| 3. ส่วนขวาสุด (ระดับบนสุด / TLD) | กล้องซูมไปที่บล็อกสีส้มทางขวาสุด สว่างขึ้นพร้อมไอคอนรูปโลกและสัญลักษณ์หมวดหมู่ร้านค้า | มีน: **“ส่วนขวาสุดเรียกว่าระดับบนสุด หรือ TLD ทำหน้าที่บอกประเภทหรือหมวดหมู่ใหญ่ของเว็บไซต์ค่ะ”** | ส่วนขวาสุด (ระดับบนสุด/TLD) ทำหน้าที่บอกประเภทหรือกลุ่มใหญ่ของเว็บไซต์ |
| 4. ส่วนตรงกลาง (ระดับที่สอง / SLD) | กล้องเลื่อนมาที่บล็อกสีฟ้าตรงกลาง สว่างขึ้นพร้อมไอคอนรูปขนมประจำร้านบ้านยาย | มีน: **“ถัดมาตรงกลางคือระดับที่สอง หรือ SLD เป็นชื่อหลักของร้านเราที่ทำให้คนจำได้ค่ะ”** | ส่วนตรงกลาง (ระดับที่สอง/SLD) คือชื่อเฉพาะหรือชื่อหลักของเว็บไซต์/ร้านค้า |
| 5. ส่วนซ้ายสุด (ระดับย่อย / Subdomain) | กล้องเลื่อนมาที่บล็อกสีเขียวทางซ้ายสุด สว่างขึ้นพร้อมไอคอนตะกร้าสินค้าสำหรับสั่งซื้อออนไลน์ | มีน: **“และทางซ้ายสุดคือโดเมนย่อย หรือ Subdomain ใช้แยกหน้าบริการย่อย เช่น หน้าสั่งซื้อขนมค่ะ”** | ส่วนซ้ายสุด (ระดับย่อย/Subdomain) คือส่วนบริการย่อยหรือแผนกย่อยภายในเว็บไซต์หลัก |
| 6. ลำดับการอ่านจากขวาไปซ้าย | ภาพแสดงลูกศรแสงวิ่งชี้ทิศทางจากบล็อกสีส้ม (ขวาสุด) -> ไปยังบล็อกสีฟ้า (กลาง) -> และไปจบที่บล็อกสีเขียว (ซ้ายสุด) อย่างชัดเจน | ลูกค้า: **“แล้วเราต้องเริ่มเรียงลำดับจากฝั่งไหนคะ?”** มีน: **“ระบบโดเมนต้องอ่านและไล่ลำดับความสำคัญจากขวาไปซ้ายเสมอค่ะ เริ่มจากกลุ่มใหญ่ขวาสุด ย้อนมาหาชื่อร้าน และบริการย่อยทางซ้ายค่ะ”** | ลำดับชั้นของโดเมนต้องอ่านและพิจารณาไล่ลำดับจาก **ขวาไปซ้าย** (จากระดับใหญ่สุดมายังส่วนย่อยสุด) |
| 7. เรียงลำดับถูกและเปิดเว็บได้ | บล็อกทั้ง 3 ล็อกเข้าหากันตามลำดับที่ถูกต้อง แล้วเปลี่ยนเป็นหน้าเว็บที่มีรูปตะกร้าขนมเค้กและขนมไทยน่ากินปรากฏขึ้น (ไม่มีตัวอักษร) | ลูกค้า: **“อ๋อ! พอเรียงลำดับจากขวามาซ้าย ก็เข้าหน้าสั่งขนมได้ทันทีเลย!”** | เมื่อเข้าใจส่วนประกอบและลำดับขวาไปซ้าย ก็สามารถระบุหน้าเว็บไซต์ได้อย่างถูกต้อง |
| 8. จบเรื่อง | มีน ลูกค้า และคุณยายยิ้มให้กันอย่างมีความสุข ฉากจบเปิดพื้นที่ชวนคิดโดยไม่เพิ่มข้อความใด ๆ บนจอ | มีน: **“ทีนี้ก็เข้าใจแล้วนะคะว่าชื่อโดเมนมีส่วนประกอบอะไรบ้าง และต้องไล่ลำดับจากทิศทางไหน”** | พร้อมเล่าความเข้าใจของตนเองเกี่ยวกับส่วนประกอบและลำดับโดเมนให้โดมฟัง |

**สำคัญ:** ถ้าสร้างวิดีโอคลิปสั้นด้วย Google Flow แยกฉาก ให้คงความต่อเนื่องของรูปลักษณ์ตัวละคร ฉาก เสียง และลำดับภาพ โดยผู้ผลิตเป็นผู้ตัดต่อให้เป็นเรื่องเดียวกัน บทด้านบนเป็นต้นแบบแก้ไขได้ตามความยาวคลิปจริง  
**ตรวจความถูกต้อง:** เมื่อแสดงลูกศรการจัดลำดับชั้น ต้องสื่อทิศทางจาก **ขวาไปซ้าย** เสมอ (บล็อกขวาสุด -> บล็อกกลาง -> บล็อกซ้ายสุด) ห้ามแสดงลูกศรไล่ลำดับความสำคัญจากซ้ายไปขวา เพราะจะทำให้ผู้เรียนจำทิศทางโครงสร้างลำดับชั้นของโดเมนผิด

### หน้าจอ 3 — สนทนากับโดม: คำถามที่ 1
**คำถามหลักบนหน้าแชท:**
> **โดม:** “จากสถานการณ์ในคลิป นักเรียนคิดว่า **ชื่อโดเมนแบ่งออกเป็นส่วนประกอบอะไรบ้าง และแต่ละส่วนทำหน้าที่ต่างกันอย่างไร** ครับ?”

**สิ่งที่นักเรียนทำ:** พิมพ์หรือพูดคำตอบอิสระ แล้วกด `ส่งคำตอบ`  
**AI วิเคราะห์:** ผู้เรียนสื่อได้หรือไม่ว่าชื่อโดเมนแบ่งเป็นส่วนย่อย ๆ ที่มีหน้าที่ต่างกัน ได้แก่ **ส่วนบอกประเภท/นามสกุล (ขวาสุด), ส่วนชื่อหลักของเว็บไซต์/ชื่อร้าน (ตรงกลาง), และส่วนบริการย่อย/หน้าย่อย (ซ้ายสุด)** โดยไม่จำเป็นต้องเรียกชื่อย่อภาษาอังกฤษ (TLD, SLD, Subdomain) ก็ได้

**ตัวอย่างคำตอบที่รับได้:**
> “แบ่งเป็น 3 ส่วนครับ มีส่วนขวาสุดใช้บอกประเภทของเว็บ ส่วนตรงกลางเป็นชื่อหลักของร้าน และส่วนซ้ายสุดเป็นหน้าบริการย่อยอย่างหน้าสั่งซื้อขนม”

**ตัวอย่างคำตอบที่ยังไม่ครบ:**
> “มีส่วนชื่อร้านกับนามสกุลเว็บครับ” — ถือเป็นคำตอบที่มีสาระถูกต้องบางส่วน **ให้คะแนนตามเกณฑ์** ไม่ปัดเป็นศูนย์และไม่บังคับแก้ทันที

**หลังส่ง Q1:** ระบบบันทึกคำตอบและคะแนน Q1 ไว้ภายใน อาจให้ข้อความยืนยันสั้น ๆ เช่น **“โดมได้รับคำตอบแล้วครับ ไปคำถามต่อไปกันเลย”** จากนั้นเปิด Q2 ทันที เพื่อไม่ให้กระบวนการตอบยืดเยื้อ  
**ความช่วยเหลือที่พร้อมใช้ภายหลัง:** `ย้อนดูช่วงมีนอธิบายส่วนประกอบ 3 ส่วน` (ฉาก 2–5) เมื่อภาพรวมคะแนนต่ำหรือคำตอบ Q1 ขาดสาระสำคัญ

### หน้าจอ 4 — สนทนากับโดม: คำถามที่ 2
**คำถามหลักบนหน้าแชท:**
> **โดม:** “จากสถานการณ์ในคลิป **เวลาอ่านหรือจัดลำดับความสำคัญของชื่อโดเมน ต้องไล่ลำดับจากทิศทางไหนไปทิศทางไหน และเรียงจากส่วนใดไปส่วนใด** ครับ?”

**AI วิเคราะห์:** นักเรียนสื่อได้หรือไม่ว่าต้องไล่ลำดับจาก **ขวาไปซ้าย** โดยเริ่มจาก **ระดับกลุ่มประเภทใหญ่สุด (ขวาสุด) มายังชื่อหลักของเว็บ (ตรงกลาง) และไปที่ส่วนบริการย่อย (ซ้ายสุด)**

**ตัวอย่างคำตอบที่รับได้:**
> “ต้องอ่านจากขวาไปซ้ายครับ โดยเริ่มจากส่วนบอกประเภทกลุ่มใหญ่ทางขวาสุด มาที่ชื่อร้านตรงกลาง แล้วค่อยไปที่บริการย่อยทางซ้ายสุด”

**ตัวอย่างคำตอบที่ถูกบางส่วน:**
> “ต้องอ่านจากขวาไปซ้ายครับ” — ระบุทิศทางถูกต้องชัดเจน แต่ยังไม่ได้อธิบายว่าไล่จากส่วนใดไปส่วนใด จึงให้ **คะแนนหลักตามเกณฑ์** พร้อม Feedback เสริมรายละเอียดการไล่ลำดับจากใหญ่ไปย่อย

**หลังส่ง Q2:** AI คำนวณคะแนนรวมจาก Q1 และ Q2 แล้ว **ให้ Feedback เพียงรอบเดียวเป็นหลัก** โดยใช้ผลรายประเด็นประกอบ
- ถ้ารวม **มากกว่า 60%** -> แสดงผล `ผ่าน` + Feedback ตามระดับ แล้วปลดล็อกวัตถุประสงค์ที่ 3 **ทันที**
- ถ้ารวม **60% หรือต่ำกว่า** -> แสดงผล `ยังไม่ผ่าน` + Feedback เฉพาะจุดอ่อน และเสนอให้ย้อนดูช่วงที่เกี่ยวข้องหรือตอบเสริมสั้น ๆ
ห้ามใช้การจำชื่อเว็บไซต์จริง การสะกดคำภาษาอังกฤษ หรือการจำสีของบล็อกในคลิปเป็นเกณฑ์ให้คะแนน เพราะเป้าหมายคือความเข้าใจส่วนประกอบและลำดับชั้น

### หน้าจอ 5 — สถานะช่วยเหลือแบบ Adaptive (เมื่อคะแนนรวมยังไม่เกิน 60%)

แนวทางช่วยนักเรียนแบบ **สั้น กระชับ และไม่เพิ่มภาระเกินจำเป็น**
1. **บอกสิ่งที่เข้าใจถูกแล้วก่อน** เช่น “นักเรียนเข้าใจถูกต้องแล้วครับว่าชื่อโดเมนต้องอ่านจากขวาไปซ้าย”
2. **ระบุสิ่งที่ยังขาดเพียง 1 ประเด็นที่สำคัญที่สุด** เช่น “แต่ยังขาดรายละเอียดว่าส่วนประกอบทั้ง 3 ส่วนของชื่อโดเมนทำหน้าที่อะไรบ้าง”
3. **ให้คำใบ้สั้น ๆ หรือปุ่มย้อนดูช่วงเกี่ยวข้อง** — Q1: ฉาก 2–5 (ส่วนประกอบ 3 ส่วน) / Q2: ฉาก 6 (ลำดับการอ่านขวาไปซ้าย)
4. **เปิดโอกาสตอบเสริมเฉพาะประเด็นนั้นหนึ่งครั้ง** โดยไม่ต้องตอบคำถามหลักทั้งสองข้อใหม่ จากนั้นประเมินคำตอบที่ดีที่สุดของแต่ละประเด็นอีกครั้ง
5. ถ้ายังไม่เกิน 60% ให้บันทึกความคืบหน้า พร้อมตัวเลือก `ย้อนดูคลิป`, `ลองอีกครั้งภายหลัง` หรือ `ขอความช่วยเหลือจากครู` โดยไม่ถามวนไม่จบ

**ตัวอย่างเมื่อได้คะแนนรวม 55%:**
> โดม: “นักเรียนบอกส่วนประกอบของชื่อเว็บได้ดีแล้วครับ แต่เรื่องลำดับการอ่านยังคลาดเคลื่อนอยู่ ลองย้อนดูช่วงที่มีนชี้ลูกศรเรียงลำดับบล็อกทั้ง 3 ส่วน แล้วตอบเสริมสั้น ๆ ว่าต้องไล่จากทิศทางไหนไปทิศทางไหนนะครับ”

**หมายเหตุ:** สำหรับผู้เรียนที่ได้ **61% ขึ้นไป** ไม่ใช้ขั้นตอนนี้เป็นข้อบังคับ สามารถเลือกทบทวนเพิ่มเติมได้ด้วยตนเอง แต่ **ต้องปลดล็อกให้ไปต่อทันที**

### หน้าจอ 6 — หน้าสรุปคะแนนและ Feedback
**เงื่อนไขผ่าน:** **คะแนนรวมมากกว่า 60%** จากคำถาม Q1 และ Q2 ไม่จำเป็นต้องตอบครบทุกสาระย่อยจึงจะผ่าน  
**องค์ประกอบที่แสดงในหน้า UI:** คะแนนรวม (เปอร์เซ็นต์), สถานะผ่าน/ยังไม่ผ่าน, สิ่งที่ทำได้ดี 1 ข้อ, สิ่งที่ควรเสริม 1 ข้อ (ถ้ามี), ข้อความให้กำลังใจแบบจริงใจ และปุ่มดำเนินการต่อ

**ตัวอย่างผู้เรียนได้ 70%:**
> **โดม:** “ผ่านภารกิจแล้วครับ! ได้ 70% นักเรียนเข้าใจชัดเจนว่าต้องอ่านลำดับโดเมนจากขวาไปซ้าย ส่วนเรื่องส่วนประกอบ ลองจำเพิ่มอีกนิดว่าทางซ้ายสุดคือส่วนบริการย่อยนะครับ พร้อมไปด่านต่อไปได้เลย”

**ตัวอย่างผู้เรียนได้ 95%:**
> **โดม:** “ยอดเยี่ยมครับ! ได้ 95% อธิบายทั้งส่วนประกอบทั้ง 3 ส่วนของชื่อโดเมน และลำดับการอ่านจากขวาไปซ้ายได้ถูกต้องครบถ้วน พร้อมไปด่านต่อไปแล้วครับ”

**ตัวอย่างผู้เรียนได้ 60%:**
> **โดม:** “ตอนนี้ได้ 60% ครับ เหลืออีกนิดเดียว ลองทบทวนเรื่องทิศทางการเรียงลำดับของชื่อโดเมน แล้วตอบเสริมสั้น ๆ อีกครั้งนะครับ”

**ปุ่มเมื่อผ่าน:** `ไปวัตถุประสงค์ที่ 3` (ปุ่มหลัก), `ทบทวนด้วยตนเอง` (ปุ่มรอง), `กลับแผนภารกิจ`  
**ปุ่มเมื่อยังไม่ผ่าน:** `ทบทวนเฉพาะจุด`, `ลองตอบเสริม`, `กลับแผนภารกิจ`

### หน้าจอ 7 — ไปวัตถุประสงค์ที่ 3

เมื่อกด `ไปวัตถุประสงค์ที่ 3` ระบบเปิดหน้าเริ่มเรียนหัวข้อ **“จำแนกประเภทของโดเมนเนมได้”** และเลือกเส้นทางเริ่มต้นตามกฎ Adaptive ของผู้เรียน ไม่ต้องทำภารกิจภาพหรือ D&D เพิ่มในเส้นทางดูของ OBJ2

## 4. วิธีให้คะแนนและ Feedback ตามระดับความถูกต้อง

### 4.1 คำถามและน้ำหนัก

มีคำถามหลักเพียง **2 ข้อ** และคิดคะแนนอย่างละ **50% ของคะแนนรวม**

| ข้อ | สิ่งที่ AI พิจารณา | คะแนนภายในข้อ |
|---|---|---:|
| **Q1: ส่วนประกอบของชื่อโดเมนและหน้าที่** | ระบุส่วนประกอบและหน้าที่ได้ถูกต้องครบทั้ง 3 ส่วน (ขวาสุด/ระดับบนสุดบอกประเภท, ตรงกลาง/ระดับสองคือชื่อหลักของร้าน, ซ้ายสุด/โดเมนย่อยคือบริการย่อย) | 100 |
|  | *(เกณฑ์ย่อยภายใน Q1: บอกส่วนนามสกุล/บอกประเภทกลุ่มใหญ่ได้ = 35 คะแนน, บอกส่วนชื่อหลักของเว็บ/ชื่อร้านได้ = 35 คะแนน, บอกส่วนบริการย่อย/หน้าย่อยได้ = 30 คะแนน)* |  |
| **Q2: ลำดับและทิศทางการอ่านชื่อโดเมน** | บอกทิศทางได้ว่าต้องอ่านหรือไล่ลำดับความสำคัญจาก **ขวาไปซ้าย** | 70 |
|  | อธิบายลำดับการไล่ระดับได้ว่าเริ่มจากส่วนกลุ่มใหญ่สุด (ขวาสุด) -> ชื่อหลัก (ตรงกลาง) -> บริการย่อย (ซ้ายสุด) | 30 |

- **สูตร:** `คะแนนรวม (%) = (คะแนน Q1 + คะแนน Q2) / 2`
- **กฎผ่าน:** `คะแนนรวม > 60` (60 ยังไม่ผ่าน; 61 ผ่าน)
- ให้คะแนน **ตามใจความ** ไม่จำเป็นต้องใช้คำศัพท์เทคนิค (TLD, SLD, Subdomain); คำว่า “ส่วนท้ายสุด/นามสกุล”, “ชื่อร้าน/ชื่อเว็บ”, “ส่วนหน้าสุด/หน้าบริการย่อย” สามารถได้คะแนนเต็มเมื่อสื่อหน้าที่ได้ถูกต้อง
- หากคำตอบมีเพียงบางส่วนของเกณฑ์ย่อย ให้คะแนนเฉพาะส่วนนั้นตามสัดส่วน ไม่ตัดสินเป็นผิดทั้งข้อ
- ถ้าผู้เรียนให้คำตอบขัดแย้งกับหลักการสำคัญ เช่น บอกว่าต้องอ่านลำดับความสำคัญจากซ้ายไปขวา AI ต้องหักคะแนนส่วนทิศทางใน Q2 พร้อมระบุความเข้าใจคลาดเคลื่อนให้ชัดเจน
- **ไม่ใช้เปอร์เซ็นต์ความมั่นใจของโมเดลแทนคะแนนความถูกต้องของผู้เรียน** ควรใช้เกณฑ์คงที่เพื่อให้ตรวจสอบได้

**ตัวอย่างการรวมคะแนน:**

| คะแนน Q1 | คะแนน Q2 | รวม | ผล |
|---:|---:|---:|---|
| 70 | 70 | 70% | ผ่าน + Feedback เสริมส่วนประกอบที่ขาด 1 ส่วน |
| 100 | 30 | 65% | ผ่าน + Feedback เน้นย้ำทิศทางขวาไปซ้าย |
| 50 | 70 | 60% | ยังไม่ผ่าน + ตอบเสริมเรื่องส่วนประกอบสั้น ๆ |
| 100 | 100 | 100% | ผ่าน + Feedback ชื่นชม |

> ตัวอย่างเป็นกรณีสาธิตวิธีรวมคะแนน ไม่ใช่คะแนนตายตัวของคำตอบทุกแบบ

### 4.2 ระดับ Feedback ตามคะแนนรวม

| คะแนนรวม | สถานะ | วิธีที่โดมให้ Feedback | ไปต่อได้หรือไม่ |
|---|---|---|---|
| **0–30%** | ยังไม่ผ่าน | บอกจุดเริ่มต้นที่เข้าใจถูก (ถ้ามี) อธิบายอย่างง่าย 1 ประเด็น และชวนดูช่วงที่เกี่ยวข้อง | ยังไม่ปลดล็อก |
| **มากกว่า 30–60%** | ยังไม่ผ่าน | ชี้ว่าใกล้ผ่านแล้ว เน้นสิ่งที่ยังขาด และให้คำใบ้/ตอบเสริมสั้น ๆ | ยังไม่ปลดล็อก |
| **มากกว่า 60–ต่ำกว่า 80%** | **ผ่าน** | ชมส่วนที่เข้าใจถูก + ชี้ประเด็นที่ยังไม่ครบอย่างกระชับ | **ปลดล็อกทันที** |
| **80–ต่ำกว่า 90%** | **ผ่าน** | ยืนยันความเข้าใจ + เสนอข้อปรับปรุงเล็กน้อยถ้ามี | **ปลดล็อกทันที** |
| **90–100%** | **ผ่าน** | ชื่นชมความถูกต้องชัดเจน + สรุปสิ่งที่ทำได้ดี | **ปลดล็อกทันที** |

**แนวข้อความ Feedback ต้องเป็นการเฉพาะบุคคล:** อ้างจากสาระที่ผู้เรียนตอบจริง เช่น หาก Q2 ตอบขวาไปซ้ายถูก แต่ Q1 ลืมพูดถึงส่วนบริการย่อย (Subdomain) ต้องบอกว่า “เข้าใจลำดับการอ่านจากขวาไปซ้ายและรู้จักชื่อหลักกับส่วนบอกประเภทแล้ว แต่ยังขาดส่วนซ้ายสุดที่ใช้บอกบริการย่อย” ไม่ใช้ข้อความกว้าง ๆ แบบเดียวกันทุกคน

**หลักลดเวลาการตอบ:** ถ้าคะแนนรวมมากกว่า 60% แม้ยังมีบางส่วนไม่ครบ ให้ผ่านก่อน พร้อม Feedback และปุ่มทบทวนแบบเลือกได้เอง โดยไม่ต้องถามใหม่เพื่อให้คะแนนเป็น 100%

### 4.3 ข้อความกำกับพฤติกรรม AI (พร้อมนำไปตั้งค่า)

> คุณคือ “โดม” ผู้ช่วย AI ของสื่อ Adaptive Learning เรื่องโดเมนเนม  
> วัตถุประสงค์ที่ 2: ให้ผู้เรียนอธิบายส่วนประกอบและลำดับของชื่อโดเมนได้  
> วิดีโอไม่มีอักษร เลข หรือชื่อโดเมนภาษาอังกฤษปรากฏบนจอ มีเพียงภาพบล็อกสัญลักษณ์และเสียงสนทนา  
> ในคลิปไม่มีโดม  
>  
> ถามคำถามหลักเพียง 2 ข้อ:  
> Q1 “จากสถานการณ์ในคลิป นักเรียนคิดว่าชื่อโดเมนแบ่งออกเป็นส่วนประกอบอะไรบ้าง และแต่ละส่วนทำหน้าที่ต่างกันอย่างไรครับ?”  
> Q2 “จากสถานการณ์ในคลิป เวลาอ่านหรือจัดลำดับความสำคัญของชื่อโดเมน ต้องไล่ลำดับจากทิศทางไหนไปทิศทางไหน และเรียงจากส่วนใดไปส่วนใดครับ?”  
>  
> หลังตอบ Q1 ให้บันทึกคะแนนแล้วไป Q2 ทันที ไม่ให้ผู้เรียนตอบซ้ำจนได้เต็มก่อน  
> เมื่อจบ Q2 ให้คำนวณคะแนนรวม (Q1 + Q2) / 2  
>  
> เกณฑ์ Q1 เต็ม 100:  
> - บอกส่วนขวาสุด / ระดับบนสุด (TLD) ว่าทำหน้าที่บอกประเภทหรือหมวดหมู่ใหญ่ของเว็บ 35 คะแนน  
> - บอกส่วนตรงกลาง / ระดับที่สอง (SLD) ว่าเป็นชื่อหลักของเว็บไซต์หรือชื่อร้าน 35 คะแนน  
> - บอกส่วนซ้ายสุด / ระดับย่อย (Subdomain) ว่าเป็นส่วนบริการย่อยหรือหน้าย่อย 30 คะแนน  
> เกณฑ์ Q2 เต็ม 100:  
> - บอกทิศทางได้ว่าต้องอ่านหรือจัดลำดับจาก “ขวาไปซ้าย” 70 คะแนน  
> - อธิบายลำดับการไล่ระดับได้ว่าเริ่มจากกลุ่มประเภทใหญ่สุด (ขวาสุด) มายังชื่อหลัก (กลาง) และบริการย่อย (ซ้ายสุด) 30 คะแนน  
> ให้คะแนนตามความหมายของคำตอบ ไม่บังคับว่าต้องใช้คำศัพท์ภาษาอังกฤษ TLD, SLD, Subdomain  
>  
> ถ้าคะแนนรวม > 60% ให้ผ่านทันที พร้อม Feedback ตามคะแนนรวม  
> 61–79%: ผ่าน + ชมส่วนที่ถูก + บอกจุดที่ยังขาด 1 ประเด็น  
> 80–89%: ผ่าน + ยืนยันสิ่งที่ทำได้ดี + ข้อปรับปรุงเล็กน้อย  
> 90–100%: ผ่าน + ชื่นชมพร้อมสรุปความเข้าใจ  
> ถ้าคะแนนรวม <= 60%: Feedback สั้น ๆ แล้วให้คำใบ้หรือย้อนดูช่วงที่เกี่ยวข้อง และเปิดโอกาสให้ตอบเสริมเฉพาะส่วนที่ขาดโดยไม่ถามข้อหลักทั้งสองใหม่  
> หากยังไม่ผ่าน ให้บันทึกความคืบหน้าและให้กลับมาทบทวนได้ ไม่ถามวนไม่จบ  
>  
> ห้ามถามว่าในคลิปพิมพ์ชื่อเว็บไซต์ว่าอะไร สะกดอย่างไร หรือบล็อกสีอะไรแทนคำว่าอะไรโดยยึดติดแค่สี  
> ห้ามนำเรื่องเงื่อนไขเอกสารการจดทะเบียน (.co.th, .ac.th, .go.th) ของด่านที่ 3 มาประเมินในด่านนี้  
> แยก “คะแนนความถูกต้อง” จาก “ความมั่นใจของ AI”  
> Feedback ต้องอิงจุดที่นักเรียนเข้าใจถูก/ยังขาดจากคำตอบจริง  

## 5. รายการชิ้นงานที่ต้องมี

| ชิ้นงาน | สิ่งที่เตรียม | หมายเหตุ |
|---|---|---|
| วิดีโอ 1 เรื่อง | ภาพเหตุการณ์ร้านขนมบ้านยาย ตัดต่อจาก 8 ฉากย่อย | **ในเฟรมไม่มีตัวอักษร/เลข/ซับเลย** |
| เสียงตัวละคร | เสียงมีน ลูกค้า (และยายหากมี) | มีคำพูดอธิบายส่วนประกอบทั้ง 3 ส่วน และลำดับ “ขวาไปซ้าย” แบบเข้าใจง่าย |
| ภาพเคลื่อนไหวกระบวนการ | บล็อก 3 ส่วนพร้อมไอคอน (รูปโลก/หมวดหมู่, ชื่อร้านขนม, ตะกร้าสั่งซื้อ) และลูกศรวิ่งจากขวาไปซ้าย | ใช้รูปร่าง สี ไอคอน และลูกศรเท่านั้น |

| หน้าเล่นวิดีโอ | เครื่องเล่นและปุ่มดูซ้ำ | ข้อความส่วนควบคุมอยู่ **นอกเฟรมคลิป** |
| หน้าแชทโดม | คำถามสองข้อ ช่องตอบอิสระ คำใบ้ และระบบให้คะแนนภายใน | ไม่มีตัวเลือกคำตอบตายตัว |
| หน้าสรุปผล | คะแนนรวม ระดับ Feedback จุดแข็ง/จุดที่ควรเสริม สถานะผ่าน และปุ่มไปต่อ | ผ่านทันทีเมื่อคะแนนรวม >60% |

## 6. Checklist ตรวจรับก่อนใช้งานจริง

- [ ] วิดีโอไม่มีอักษรไทย อังกฤษ ตัวเลข ชื่อโดเมน คำว่า TLD/SLD/Subdomain ซับไตเติล ป้ายเขียน หรืออักษรเพี้ยนทุกชนิด
- [ ] ตัวละครในคลิปมีเฉพาะมีน ลูกค้า และยายตามที่จำเป็น ไม่มีโดม
- [ ] คลิปเล่าเรื่องจากปัญหาความสับสนของส่วนประกอบชื่อเว็บ ไปสู่การแยกแยะ 3 ส่วน การเรียงลำดับขวาไปซ้าย และเปิดหน้าสั่งขนมสำเร็จ
- [ ] คำอธิบายส่วนประกอบทั้ง 3 ส่วน (ระดับบนสุด/TLD, ระดับที่สอง/SLD, โดเมนย่อย/Subdomain) และคำว่า “ขวาไปซ้าย” **ได้ยินในเสียงพูด** พร้อมคำอธิบายระดับพื้นฐาน
- [ ] ภาพสื่อทิศทางทางเทคนิคถูกต้อง: ลูกศรชี้ลำดับความสำคัญจาก **ขวาสุด (กลุ่มใหญ่) -> ตรงกลาง (ชื่อหลัก) -> ซ้ายสุด (บริการย่อย)**
- [ ] นักเรียนดูคลิปจบแล้วมีคำถามหลัก **2 ข้อเท่านั้น**
- [ ] ไม่มีคำถามเกี่ยวกับการจำตัวสะกดชื่อเว็บไซต์ หรืออ่านตัวอักษรในคลิป
- [ ] Q1 วัดว่าอธิบายส่วนประกอบของชื่อโดเมนและหน้าที่ได้จริง
- [ ] Q2 วัดว่าอธิบายลำดับและทิศทางการอ่านจากขวาไปซ้ายได้จริง
- [ ] ระบบคำนวณ `Q1 50% + Q2 50%` และใช้เกณฑ์ **คะแนนรวม >60%** (60 ยังไม่ผ่าน)
- [ ] นักเรียนไป Q2 ได้ทันทีหลังตอบ Q1 โดยไม่บังคับให้ Q1 สมบูรณ์ก่อน
- [ ] Feedback ปรับตามระดับคะแนนและจุดที่นักเรียนขาดจริง แม้ผ่านก็ยังมีข้อแนะนำ
- [ ] ผู้เรียนที่ผ่านไม่ต้องตอบซ้ำเพื่อเพิ่มคะแนน แต่เลือกทบทวนเองได้
- [ ] หากไม่ผ่าน AI ถามนำจากเหตุการณ์/บทพูดในคลิป ให้ตอบเสริมเฉพาะจุด ไม่ถามวนไม่จบ
- [ ] หากคะแนนรวมมากกว่า 60% ไปวัตถุประสงค์ที่ 3 ได้ โดยไม่มีภารกิจภาพหรือเกมลากวางต่อท้ายในเส้นทางนี้

## 7. สรุปหนึ่งบรรทัด

**เข้าด่าน -> รับภารกิจ -> ดูคลิปสถานการณ์ (ภาพและเสียงเท่านั้น) -> ตอบโดม 2 ข้อ (ส่วนประกอบ + ลำดับขวาไปซ้าย) -> AI คิดคะแนนรวมและ Feedback ตามระดับ -> >60% ผ่านทันที -> ไปวัตถุประสงค์ที่ 3; ถ้า <=60% ให้คำใบ้และทบทวนเฉพาะจุด**

---

### บันทึกสิ่งที่กำหนดให้สอดคล้องกับมาตรฐานโครงการ
1. **งดใส่ข้อความ TLD, SLD, Subdomain, และชื่อเว็บไซต์ภาษาอังกฤษทับลงในคลิปวิดีโอ** โดยใช้บล็อกสี ไอคอน และลูกศรแทนทั้งหมด
2. **งดถามข้อมูลเฉพาะเจาะจงที่ไม่ปรากฏในคลิป** เช่น ตัวสะกดชื่อเว็บไซต์ของร้านขนม
3. **ออกแบบคำถามหลัก 2 ข้อให้ตรงกับวัตถุประสงค์ที่ 2** (Q1 วัดเรื่องส่วนประกอบ, Q2 วัดเรื่องลำดับขวาไปซ้าย)
4. **ใช้เสียงพากย์ตัวละครและภาพแอนิเมชันกระบวนการเป็นแหล่งความรู้หลัก** โดยออกเสียงคำศัพท์สำคัญในบทพูดได้ตามปกติ
5. **คงผู้ช่วย AI โดมไว้ใน UI หลังดูคลิปเท่านั้น** และจบเส้นทางดูวิดีโอด้วยคำถามสนทนา 2 ข้อโดยไม่มีมินิเกมแทรก
6. **ใช้เกณฑ์ผ่านเดียวกันกับทั้งระบบ:** คะแนนรวมมากกว่า 60% ผ่านทันที พร้อม Feedback เฉพาะบุคคลตามระดับคะแนน
7. **ใช้ Flow การประเมินแบบกระชับ:** ตอบ Q1 แล้วไป Q2 ทันที และเมื่อผ่านเกณฑ์แล้วสามารถข้ามไปวัตถุประสงค์ที่ 3 ได้เลย
