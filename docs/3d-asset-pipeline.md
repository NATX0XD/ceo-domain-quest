# ทำ 3D ให้สวย — ต้องใช้อะไรบ้าง

บันทึกเมื่อ 29 กันยายน 2569

---

## 1. ตอบคำถามตรง ๆ ก่อน

> **"ตอนสร้าง object ไม่ต้องใช้ lib นอกเหรอ ไม่งั้น 3D ออกมาไม่สวย"**

ถูกต้อง แต่สิ่งที่ขาดไม่ใช่ **library** — เป็น **โปรแกรมปั้นโมเดล**

Three.js มีรูปทรงในตัวให้แค่นี้: `BoxGeometry`, `SphereGeometry`, `CylinderGeometry`, `ConeGeometry`, `TorusGeometry`, `PlaneGeometry`
เอามาต่อกันได้แค่หุ่นกล่อง ๆ แบบที่ `netrise` เป็นอยู่ตอนนี้ (ลูกบาศก์สี) **ไม่มีไลบรารี JavaScript ตัวไหนแก้เรื่องนี้ได้** เพราะปัญหาไม่ได้อยู่ที่โค้ด

Interland ก็เจอข้อจำกัดเดียวกัน วิธีที่เขาใช้คือ **ปั้นใน Blender** แล้ว export เข้ามา — ยืนยันจากกรณีศึกษาของ 14islands ผู้พัฒนาจริง

---

## 2. Pipeline ที่ถูกต้อง

```
ปั้น/ดาวน์โหลดโมเดล  →  แต่งใน Blender  →  export .glb  →  บีบอัด  →  โหลดใน Three.js
   (Blender / CC0)                          (+ Draco)      (GLTFLoader)
```

| ขั้น | เครื่องมือ | ฟรีไหม |
|---|---|---|
| ปั้นโมเดล | **Blender** | ฟรี โอเพนซอร์ส |
| หาโมเดลสำเร็จ | Kenney.nl, Quaternius, Poly Pizza (สัญญาอนุญาต CC0 ใช้เชิงพาณิชย์ได้) | ฟรี |
| export | Blender → glTF 2.0 (`.glb`) | ฟรี ในตัว Blender |
| บีบอัด | `gltf-transform` (Draco) | ฟรี ผ่าน npm |
| โหลดเข้าเกม | `GLTFLoader` **มากับ Three.js อยู่แล้ว** | ไม่ต้องลงไลบรารีเพิ่ม |

**ทางลัดที่ใช้ได้จริงในเวลาจำกัด:** ดาวน์โหลดโมเดล CC0 จาก Kenney หรือ Quaternius → เปิดใน Blender → เปลี่ยนสีวัสดุให้เข้าธีมร้าน → export `.glb`
ไม่ต้องปั้นเองตั้งแต่ศูนย์ ซึ่งกินเวลาเป็นสัปดาห์

## 3. ความสวยมาจากไหนจริง ๆ

เรียงจากผลกระทบมากไปน้อย ข้อ 1–3 สำคัญกว่าตัวโมเดลเอง

| ลำดับ | สิ่งที่ทำ | เครื่องมือ | ผล |
|:---:|---|---|---|
| 1 | **แสงและเงา** — ไฟนุ่ม ๆ 3 ดวง + เงาที่ตกจริง (`castShadow` / `receiveShadow`) | Three.js ในตัว | ต่างกันมากที่สุด |
| 2 | **Environment map (HDRI)** — สะท้อนสภาพแวดล้อมลงบนวัสดุ | `RGBELoader` (มากับ Three.js) | วัสดุดูมีน้ำหนัก ไม่แบน |
| 3 | **โทนสีจำกัด** — เลือกสีหลัก 4–5 สีแล้วใช้ทั้งฉาก | ตัดสินใจเอง ไม่ต้องมีเครื่องมือ | ทำให้ดู "ตั้งใจออกแบบ" |
| 4 | **Post-processing** — bloom, ambient occlusion | `EffectComposer` (มากับ Three.js ในโฟลเดอร์ `examples/jsm`) | เพิ่มมิติ แต่กินเครื่อง |
| 5 | ความละเอียดของโมเดล | Blender | สำคัญน้อยที่สุด |

**ทุกอย่างในตารางนี้มากับ Three.js อยู่แล้ว** ไม่ต้องลงไลบรารีนอกเลย
สิ่งเดียวที่ต้องหาข้างนอกคือตัวโมเดล `.glb`

## 4. สรุปสำหรับโปรเจกต์นี้

**ถ้าเลือกทำ 3D:**
- ต้องมีคนเปิด Blender จริง ๆ อย่างน้อย 1 คน ตั้งแต่ตอนนี้
- ใช้โมเดล CC0 เป็นฐาน แต่งสีใหม่ อย่าปั้นเองตั้งแต่ศูนย์
- แยกไฟล์ `.glb` ต่อฉาก + บีบด้วย Draco — **อย่าฝังโมเดลลง bundle แบบ Interland** (bundle เขา 25 MB เปิดครั้งแรกบนเน็ตโรงเรียนจะช้ามาก)

**ถ้าไม่มีคนทำ Blender:** อย่าฝืนทำ 3D
ภาพ isometric 2D ที่วาดดี (แบบภาพ flow ที่ทีมทำไว้แล้ว) **ดูดีกว่า** 3D ที่ทำครึ่ง ๆ กลาง ๆ มาก และใช้เวลาน้อยกว่า 3 เท่า
จุดนี้ตัดสินใจก่อนวันที่ 2 ตุลาคม ไม่งั้นจะไม่ทันวันที่ 7
