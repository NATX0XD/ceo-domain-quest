# ภาพหน้าจอสำหรับสไลด์นำเสนอ

เก็บเมื่อ **30 กันยายน 2569** จากห้อง **UAT777** ที่มีข้อมูลจริง (ยกเว้น 2 ใบที่ขึ้นต้นด้วย `demo-` ดูหัวข้อ "ภาพที่ถ่ายจากห้องข้อมูลจริงไม่ได้")
อ่านคู่กับ `docs/presentation-outline.md`

## ถ่ายใหม่ยังไง

```bash
npm run dev                                  # ต้องมี dev server พอร์ต 3000 เปิดอยู่
npx tsx scripts/capture-screenshots.ts       # ถ่ายใหม่ทั้งชุด ทับของเดิม
npx tsx scripts/capture-screenshots.ts --room UAT777 --out docs/screenshots
```

สคริปต์ **อ่านอย่างเดียว พิสูจน์ได้** กันไว้ 3 ชั้น
1. ไม่ล็อกอินผ่าน API — เซ็นคุกกี้จากแถวที่มีอยู่แล้วด้วย `signStudentSession()` ของโปรเจกต์เอง
2. ปัดตกทุกคำขอที่ไม่ใช่ GET ในเบราว์เซอร์ (รอบล่าสุดปัดตก 25 ครั้ง ทั้งหมดเป็น `POST /api/presence`)
3. ถ่ายลายนิ้วมือฐานข้อมูล 9 ตารางก่อนและหลัง แล้วเทียบ — รอบล่าสุด **ไม่เปลี่ยนแม้แถวเดียว**

`manifest.json` ในโฟลเดอร์นี้บันทึกไว้ว่าแต่ละใบถ่ายจากหน้าไหน ใช้คุกกี้ของใคร ขนาดเท่าไร และผลตรวจสุขภาพหน้า

## ภาพที่ถ่ายจากห้องข้อมูลจริงไม่ได้ (ขึ้นต้นด้วย `demo-`)

2 ใบนี้ถ่ายจาก **ห้องสาธิตที่สร้างใหม่แล้วลบทิ้งทันที** ไม่ได้แตะ UAT777 เลย
ข้อมูลในภาพจึงเป็นชื่อร้านชุดเดียวกับที่ seed ใช้ แต่ไม่ใช่แถวเดียวกับในห้อง UAT777 ตอนนี้

| ไฟล์ | ทำไมถ่ายจาก UAT777 ไม่ได้ |
|---|---|
| `demo-01-mission-hints.png` | เปิดหน้า `/mission/[id]` **เขียนฐานข้อมูลตั้งแต่ตอนเรนเดอร์** (สร้างแถวความคืบหน้าถ้ายังไม่มี และฝากงานให้ AI แต่งเรื่องเปิดภารกิจ) · และการเปิดคำใบ้เป็น `POST /api/hint` |
| `demo-02-result-3sources.png` | คะแนนที่ผู้เรียนให้ตัวเองในห้อง UAT777 เป็นรูปแบบเก่า (ไม่มีคีย์ `dimensions`) ตารางจึงขึ้นเป็น **ฟอร์มให้คะแนน** แทนตารางเทียบ · การเติมให้ครบต้องยิง `POST /api/self-assess` ซึ่งเป็นการแก้ข้อมูลในห้องนั้น |

> **ถ้าอยากให้ 2 ใบนี้เป็นข้อมูลจริงจาก UAT777** ต้องให้เจ้าของ `scripts/seed-uat.ts` เติม 2 อย่างตอน seed
> (1) เปิดคำใบ้ให้นักเรียนอย่างน้อย 1 คนผ่าน `POST /api/hint` หรือเขียน `mission_progress.hints_used` พร้อมมีแถวจริง
> (2) เขียนคะแนนที่ผู้เรียนให้ตัวเองในรูปแบบใหม่ `self_scores.dimensions = { "dim-naming": 2, ... }`
> แล้วรัน `npx tsx scripts/capture-screenshots.ts` ใหม่ ภาพจะมาจากห้องจริงทั้งชุด

## ข้อควรระวังตอนเอาขึ้นสไลด์

- ภาพทุกใบถ่ายจาก **dev server** จึงมีปุ่มกลมของแถบเครื่องมือ Next อยู่มุมซ้ายล่าง — ไม่มีใน production
  ถ้าจะให้สะอาด ให้ `npm run build && npm start` แล้วถ่ายใหม่ด้วยสคริปต์เดิม
- นาฬิกาที่มุมขวาบนของหน้านักเรียนเป็นเวลาที่เหลือของคาบจริง ตัวเลขจะไม่ตรงกันระหว่างใบ
- ห้อง UAT777 ถูก seed ใหม่ได้ตลอด (ระหว่างเก็บภาพรอบนี้ก็ถูก seed ใหม่ไป 1 ครั้ง) **ตัวเลขบนภาพกับในห้องจึงต้องถ่ายใหม่พร้อมกันเสมอ** ถ้าจะอ้างตัวเลขบนเวที
