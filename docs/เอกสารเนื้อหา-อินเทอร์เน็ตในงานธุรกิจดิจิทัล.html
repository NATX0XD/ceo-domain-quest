คำอธิบายรายวิชาและโครงสร้างหน่วยการเรียน

จุดประสงค์รายวิชา

  1. รู้และเข้าใจเกี่ยวกับระบบอินเทอร์เน็ต
  2. มีทักษะในการใช้งานเว็บเบราว์เซอร์ในงานอินเทอร์เน็ต
  3. ใช้โปรแกรมและบริการบนอินเทอร์เน็ต ได้แก่ การสืบค้นข้อมูล อีเมล ธุรกรรมทางอิเล็กทรอนิกส์ และสื่อสังคมออนไลน์ ประยุกต์เพื่อธุรกิจดิจิทัลได้อย่างปลอดภัย
  4. มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงานด้วยความละเอียดรอบคอบ

สมรรถนะรายวิชา

  1. แสดงความรู้เกี่ยวกับหลักการทำงานของระบบอินเทอร์เน็ตและบริการบนอินเทอร์เน็ตเพื่อธุรกิจดิจิทัล
  2. ใช้งานเว็บเบราว์เซอร์และปลั๊กอินเสริมตามลักษณะงาน
  3. สืบค้น ประเมิน และอ้างอิงข้อมูลจากอินเทอร์เน็ตเพื่อใช้ในงานธุรกิจ
  4. ใช้อีเมลและทำธุรกรรมทางอิเล็กทรอนิกส์ตามหลักความปลอดภัย
  5. ใช้สื่อสังคมออนไลน์เพื่อการประชาสัมพันธ์และการตลาดของธุรกิจดิจิทัล

สาระสำคัญ

อินเทอร์เน็ตเป็นเครือข่ายคอมพิวเตอร์ขนาดใหญ่ที่เชื่อมโยงเครือข่ายย่อยทั่วโลกเข้าด้วยกันภายใต้มาตรฐานเดียวกัน ทำให้ผู้ใช้สามารถแลกเปลี่ยนข้อมูล ติดต่อสื่อสาร และทำธุรกรรมได้ตลอดเวลาโดยไม่จำกัดสถานที่ ความเข้าใจองค์ประกอบและหลักการทำงานของอินเทอร์เน็ตเป็นพื้นฐานสำคัญที่ทำให้ผู้เรียนใช้บริการต่าง ๆ บนอินเทอร์เน็ตได้อย่างถูกต้อง ปลอดภัย และนำไปประยุกต์ในงานธุรกิจดิจิทัลได้

จุดประสงค์เชิงพฤติกรรม
  1. บอกความหมายและความสำคัญของอินเทอร์เน็ตได้
  2. อธิบายองค์ประกอบและหลักการทำงานของอินเทอร์เน็ตได้
  3. อธิบายบทบาทของอินเทอร์เน็ตที่มีต่อธุรกิจดิจิทัลได้

1.1 ความหมายและความสำคัญของอินเทอร์เน็ต

อินเทอร์เน็ต (Internet) หมายถึง เครือข่ายคอมพิวเตอร์ขนาดใหญ่ที่เกิดจากการเชื่อมโยงเครือข่ายย่อยจำนวนมากทั่วโลกเข้าด้วยกัน โดยใช้ชุดโพรโทคอลมาตรฐานเดียวกันคือ TCP/IP ทำให้คอมพิวเตอร์และอุปกรณ์ต่างชนิด ต่างระบบปฏิบัติการ สามารถรับส่งข้อมูลถึงกันได้ คำว่า Internet มาจาก Inter (ระหว่าง) รวมกับ Network (เครือข่าย) จึงมีความหมายตามตัวอักษรว่า "เครือข่ายระหว่างเครือข่าย"

ลักษณะสำคัญที่ทำให้อินเทอร์เน็ตแตกต่างจากเครือข่ายทั่วไป มีดังนี้

  • ไม่มีเจ้าของเพียงรายเดียว — เกิดจากความร่วมมือของผู้ให้บริการและองค์กรจำนวนมาก ไม่มีหน่วยงานใดเป็นเจ้าของทั้งระบบ
  • ใช้มาตรฐานเปิด — ทุกเครื่องสื่อสารกันด้วยโพรโทคอลชุดเดียวกัน ทำให้อุปกรณ์ต่างยี่ห้อทำงานร่วมกันได้
  • ทำงานตลอด 24 ชั่วโมง — ไม่มีวันหยุด ไม่มีเวลาทำการ
  • ไร้พรมแดน — ระยะทางไม่มีผลต่อการเข้าถึงข้อมูล

ความสำคัญของอินเทอร์เน็ต

ด้านความสำคัญ
การสื่อสารติดต่อสื่อสารได้รวดเร็ว ประหยัดค่าใช้จ่าย ทั้งข้อความ เสียง ภาพ และวิดีโอ
การเข้าถึงข้อมูลสืบค้นความรู้และข้อมูลจากแหล่งทั่วโลกได้ทันที
การศึกษาเรียนรู้ได้ด้วยตนเองทุกที่ทุกเวลาผ่านบทเรียนออนไลน์
ธุรกิจและการค้าขยายตลาด ลดต้นทุน เปิดร้านออนไลน์ รับชำระเงิน และให้บริการลูกค้าได้ตลอดเวลา
การบริการภาครัฐยื่นเอกสาร ชำระภาษี และติดต่อราชการผ่านระบบออนไลน์

1.2 พัฒนาการของอินเทอร์เน็ต

ช่วงเวลาเหตุการณ์สำคัญ
พ.ศ. 2512กระทรวงกลาโหมสหรัฐอเมริกาพัฒนาเครือข่าย ARPANET เชื่อมคอมพิวเตอร์ระหว่างมหาวิทยาลัย 4 แห่ง ถือเป็นต้นกำเนิดของอินเทอร์เน็ต
พ.ศ. 2526เริ่มใช้โพรโทคอล TCP/IP เป็นมาตรฐานกลาง ทำให้เครือข่ายต่าง ๆ เชื่อมต่อกันได้
พ.ศ. 2534Tim Berners-Lee พัฒนา World Wide Web (WWW) ทำให้การเข้าถึงข้อมูลอยู่ในรูปหน้าเว็บที่มีลิงก์เชื่อมโยง
พ.ศ. 2530–2535ประเทศไทยเริ่มเชื่อมต่ออินเทอร์เน็ตครั้งแรกในกลุ่มสถาบันการศึกษา และเปิดใช้เชิงพาณิชย์ในเวลาต่อมา
พ.ศ. 2550 เป็นต้นมาสมาร์ตโฟนและอินเทอร์เน็ตความเร็วสูงแพร่หลาย เกิดสื่อสังคมออนไลน์ อีคอมเมิร์ซ และธุรกิจดิจิทัลเต็มรูปแบบ

1.3 องค์ประกอบของระบบอินเทอร์เน็ต

การใช้งานอินเทอร์เน็ตหนึ่งครั้ง ต้องอาศัยองค์ประกอบร่วมกัน 4 ส่วน ดังนี้

1) ฮาร์ดแวร์ (Hardware)

อุปกรณ์หน้าที่
เครื่องลูกข่าย (Client)คอมพิวเตอร์ โน้ตบุ๊ก แท็บเล็ต สมาร์ตโฟน ที่ผู้ใช้ใช้เรียกดูข้อมูล
เซิร์ฟเวอร์ (Server)เครื่องที่ให้บริการข้อมูล เช่น เว็บเซิร์ฟเวอร์ เมลเซิร์ฟเวอร์ ฐานข้อมูล
โมเด็ม (Modem)แปลงสัญญาณระหว่างสายสัญญาณของผู้ให้บริการกับอุปกรณ์ในบ้านหรือสำนักงาน
เราเตอร์ (Router)เลือกเส้นทางส่งข้อมูลระหว่างเครือข่าย และแจกหมายเลข IP ให้อุปกรณ์ภายใน
สวิตช์ (Switch) / จุดกระจายสัญญาณ (Access Point)กระจายการเชื่อมต่อแบบมีสายและไร้สายให้อุปกรณ์ในเครือข่ายเดียวกัน
สื่อนำสัญญาณสายแลน สายไฟเบอร์ออปติก คลื่นวิทยุ Wi-Fi และเครือข่ายโทรศัพท์เคลื่อนที่

2) ซอฟต์แวร์ (Software)

  • เว็บเบราว์เซอร์ ใช้แสดงผลหน้าเว็บ เช่น Google Chrome, Microsoft Edge, Mozilla Firefox, Safari
  • โปรแกรมรับส่งอีเมล เช่น Gmail, Microsoft Outlook
  • แอปพลิเคชันสื่อสารและทำงานร่วมกัน เช่น LINE, Microsoft Teams, Google Workspace
  • โพรโทคอล ซึ่งเป็นข้อตกลงของการรับส่งข้อมูล

3) ผู้ให้บริการอินเทอร์เน็ต (ISP: Internet Service Provider)

องค์กรที่ให้บริการเชื่อมต่ออินเทอร์เน็ตแก่ผู้ใช้ทั่วไป เช่น AIS, TRUE, NT โดยผู้ใช้ต้องสมัครใช้บริการและชำระค่าบริการตามแพ็กเกจ ผู้ให้บริการจะจัดสรรหมายเลข IP และดูแลเส้นทางการเชื่อมต่อออกสู่อินเทอร์เน็ต

4) ผู้ใช้งาน (User)

ผู้ใช้ต้องมีความรู้พื้นฐานในการใช้อุปกรณ์ ใช้บริการอย่างถูกต้องตามกฎหมายและจริยธรรม รวมถึงมีความระมัดระวังด้านความปลอดภัย

1.4 หลักการทำงานของอินเทอร์เน็ต

1) โพรโทคอล TCP/IP

โพรโทคอล (Protocol) คือข้อตกลงหรือกฎเกณฑ์ที่ใช้ควบคุมการรับส่งข้อมูลระหว่างอุปกรณ์ในเครือข่าย โพรโทคอลหลักของอินเทอร์เน็ตคือ TCP/IP ซึ่งประกอบด้วย

  • TCP (Transmission Control Protocol) ทำหน้าที่แบ่งข้อมูลออกเป็นชิ้นเล็ก ๆ เรียกว่า แพ็กเก็ต (Packet) กำกับลำดับ และตรวจสอบว่าข้อมูลถึงปลายทางครบถ้วน หากชิ้นใดสูญหายจะขอส่งใหม่
  • IP (Internet Protocol) ทำหน้าที่กำหนดที่อยู่ต้นทางและปลายทาง และเลือกเส้นทางส่งแพ็กเก็ตไปยังปลายทาง

2) หมายเลขไอพี (IP Address)

หมายเลขประจำตัวของอุปกรณ์ทุกเครื่องที่เชื่อมต่อเครือข่าย ใช้ระบุว่าอุปกรณ์ใดเป็นผู้ส่งและผู้รับ ปัจจุบันมี 2 รูปแบบ

รูปแบบตัวอย่างลักษณะ
IPv4192.168.1.10ตัวเลข 4 ชุด ชุดละ 0–255 คั่นด้วยจุด รองรับได้ประมาณ 4,300 ล้านหมายเลข
IPv62001:0db8::7334เลขฐานสิบหก 8 ชุด คั่นด้วยเครื่องหมายทวิภาค รองรับจำนวนอุปกรณ์ได้มหาศาล

3) ชื่อโดเมนและระบบ DNS

มนุษย์จำหมายเลข IP ได้ยาก จึงใช้ ชื่อโดเมน (Domain Name) แทน เช่น www.moe.go.th และมีระบบ DNS (Domain Name System) ทำหน้าที่แปลงชื่อโดเมนเป็นหมายเลข IP เปรียบได้กับสมุดโทรศัพท์ของอินเทอร์เน็ต

4) URL และโพรโทคอลของเว็บ

URL (Uniform Resource Locator) คือที่อยู่ของทรัพยากรบนอินเทอร์เน็ต มีโครงสร้างดังนี้

https://   www.example.co.th   /product   /item.html

ส่วนประกอบความหมาย
https://โพรโทคอลที่ใช้ โดย HTTPS เป็นรูปแบบที่เข้ารหัสข้อมูลระหว่างทาง ปลอดภัยกว่า HTTP
www.example.co.thชื่อโดเมนของเว็บไซต์
/productโฟลเดอร์หรือเส้นทางภายในเว็บไซต์
/item.htmlชื่อไฟล์หรือหน้าเว็บที่ต้องการเปิด

5) ลำดับการทำงานเมื่อเปิดเว็บไซต์หนึ่งครั้ง

  1. ผู้ใช้พิมพ์ URL ในเบราว์เซอร์
  2. เบราว์เซอร์สอบถามหมายเลข IP ของชื่อโดเมนนั้นจากเซิร์ฟเวอร์ DNS
  3. เมื่อได้หมายเลข IP เบราว์เซอร์ส่งคำขอ (Request) ไปยังเว็บเซิร์ฟเวอร์ปลายทาง
  4. ข้อมูลถูกแบ่งเป็นแพ็กเก็ตและส่งผ่านเราเตอร์หลายจุดจนถึงปลายทาง
  5. เว็บเซิร์ฟเวอร์ตอบกลับ (Response) เป็นไฟล์ HTML รูปภาพ และไฟล์อื่น ๆ
  6. เบราว์เซอร์ประกอบข้อมูลที่ได้รับแล้วแสดงผลเป็นหน้าเว็บให้ผู้ใช้เห็น

1.5 บริการพื้นฐานบนอินเทอร์เน็ต

บริการลักษณะการใช้งาน
World Wide Web (WWW)บริการเว็บไซต์ที่แสดงข้อมูลในรูปข้อความ ภาพ เสียง และวิดีโอ เชื่อมโยงกันด้วยลิงก์
จดหมายอิเล็กทรอนิกส์ (E-mail)รับส่งข้อความและไฟล์แนบระหว่างบุคคลและองค์กร
การสืบค้นข้อมูล (Search Engine)ค้นหาข้อมูลจากเว็บไซต์ทั่วโลกด้วยคำสำคัญ
สื่อสังคมออนไลน์ (Social Media)สร้างและแบ่งปันเนื้อหา สร้างชุมชนผู้ติดตาม ใช้ประชาสัมพันธ์ธุรกิจ
พาณิชย์อิเล็กทรอนิกส์ (E-Commerce)ซื้อขายสินค้าและบริการผ่านระบบออนไลน์
บริการคลาวด์ (Cloud Service)จัดเก็บไฟล์และใช้งานโปรแกรมผ่านอินเทอร์เน็ต เช่น Google Drive, OneDrive
การประชุมออนไลน์ประชุมผ่านภาพและเสียง เช่น Google Meet, Zoom, Microsoft Teams

1.6 บทบาทของอินเทอร์เน็ตต่อธุรกิจดิจิทัล

ธุรกิจดิจิทัล (Digital Business) คือการดำเนินธุรกิจที่ใช้เทคโนโลยีดิจิทัลเป็นเครื่องมือหลักในการสร้างคุณค่า ตั้งแต่การผลิต การตลาด การขาย ไปจนถึงการบริการหลังการขาย โดยมีอินเทอร์เน็ตเป็นโครงสร้างพื้นฐาน

บทบาทตัวอย่างการใช้งานจริง
ขยายช่องทางการขายเปิดร้านบนแพลตฟอร์มออนไลน์ ขายผ่านเพจ และไลฟ์ขายสินค้า เข้าถึงลูกค้านอกพื้นที่
ลดต้นทุนการดำเนินงานไม่ต้องเช่าหน้าร้าน ใช้เอกสารอิเล็กทรอนิกส์แทนกระดาษ ใช้ระบบคลาวด์แทนเซิร์ฟเวอร์ของตนเอง
สื่อสารกับลูกค้าตอบแชท ส่งอีเมลแจ้งสถานะคำสั่งซื้อ และรับข้อร้องเรียนได้ทันที
การตลาดแบบวัดผลได้ดูสถิติผู้เข้าชม อัตราการคลิก และยอดขายจากโฆษณาออนไลน์แต่ละชิ้น
การชำระเงินอิเล็กทรอนิกส์รับชำระผ่าน QR Code, Mobile Banking และบัตรเครดิต ลดการถือเงินสด
การทำงานร่วมกันใช้เอกสารออนไลน์ร่วมกัน ประชุมทางไกล และทำงานจากที่ใดก็ได้
การใช้ข้อมูลเพื่อการตัดสินใจเก็บข้อมูลพฤติกรรมลูกค้าเพื่อวางแผนสินค้าและโปรโมชัน
กรณีศึกษาสั้น ร้านขายเสื้อผ้าขนาดเล็กในต่างจังหวัด เดิมขายเฉพาะหน้าร้านและมีลูกค้าจำกัด เมื่อเปิดเพจบนสื่อสังคมออนไลน์ ใช้อีเมลติดต่อผู้ผลิต รับชำระเงินผ่าน QR Code และใช้บริการขนส่งที่จองผ่านเว็บไซต์ ทำให้ขายได้ทั่วประเทศโดยไม่ต้องเพิ่มพนักงานหน้าร้าน กรณีนี้แสดงให้เห็นว่าทักษะอินเทอร์เน็ตพื้นฐานส่งผลโดยตรงต่อรายได้ของธุรกิจ

สรุปหน่วยที่ 1

อินเทอร์เน็ตคือเครือข่ายที่เชื่อมเครือข่ายย่อยทั่วโลกด้วยโพรโทคอล TCP/IP มีองค์ประกอบสำคัญ 4 ส่วน คือ ฮาร์ดแวร์ ซอฟต์แวร์ ผู้ให้บริการ และผู้ใช้งาน การทำงานอาศัยหมายเลข IP ระบบ DNS และการส่งข้อมูลแบบแพ็กเก็ต บริการบนอินเทอร์เน็ตมีหลายรูปแบบและถูกนำมาใช้เป็นโครงสร้างพื้นฐานของธุรกิจดิจิทัล ทั้งด้านการขาย การตลาด การเงิน และการทำงานร่วมกัน

คำถามทบทวนหน่วยที่ 1

  1. จงอธิบายความหมายของอินเทอร์เน็ตพร้อมยกตัวอย่างลักษณะเด่นมา 2 ข้อ
  2. องค์ประกอบของระบบอินเทอร์เน็ตมีกี่ส่วน อะไรบ้าง
  3. TCP และ IP มีหน้าที่แตกต่างกันอย่างไร
  4. DNS มีความจำเป็นต่อผู้ใช้อย่างไร
  5. จงยกตัวอย่างบทบาทของอินเทอร์เน็ตต่อธุรกิจดิจิทัลมา 3 ข้อ พร้อมอธิบายประกอบ

หน่วยที่ 2 การใช้งานเว็บเบราว์เซอร์

สาระสำคัญ

เว็บเบราว์เซอร์เป็นโปรแกรมหลักที่ผู้ใช้ใช้เข้าถึงบริการต่าง ๆ บนอินเทอร์เน็ต การรู้จักส่วนประกอบ การจัดการแท็บ บุ๊กมาร์ก ประวัติการใช้งาน การตั้งค่าความเป็นส่วนตัว และการติดตั้งปลั๊กอินเสริมอย่างเหมาะสม ช่วยให้ทำงานได้เร็วขึ้น เป็นระบบ และปลอดภัยมากขึ้น ซึ่งเป็นทักษะพื้นฐานที่จำเป็นในงานธุรกิจดิจิทัล

จุดประสงค์เชิงพฤติกรรม
  1. บอกส่วนประกอบและหน้าที่ของเว็บเบราว์เซอร์ได้
  2. ปฏิบัติการเปิด–ปิดเว็บไซต์และจัดการแท็บได้
  3. จัดการบุ๊กมาร์กและประวัติการใช้งานได้
  4. ติดตั้งและใช้งานปลั๊กอินเสริมได้

2.4 การจัดการบุ๊กมาร์กและประวัติการใช้งาน

บุ๊กมาร์ก (Bookmark)

บุ๊กมาร์กคือการบันทึกที่อยู่เว็บไซต์ไว้เพื่อเรียกใช้ภายหลังโดยไม่ต้องจำ URL ในงานธุรกิจควรจัดบุ๊กมาร์กเป็นโฟลเดอร์ตามลักษณะงาน เช่น

  • โฟลเดอร์ "ผู้ผลิตและคู่ค้า" เก็บเว็บไซต์ของซัพพลายเออร์
  • โฟลเดอร์ "ขนส่ง" เก็บระบบติดตามพัสดุ
  • โฟลเดอร์ "การเงิน" เก็บระบบธนาคารและใบเสร็จอิเล็กทรอนิกส์
  • โฟลเดอร์ "การตลาด" เก็บหน้าสถิติของเพจและโฆษณา

ขั้นตอนการเพิ่มบุ๊กมาร์ก คือ เปิดหน้าเว็บที่ต้องการ กดสัญลักษณ์ดาวที่แถบที่อยู่หรือกด Ctrl + D ตั้งชื่อให้สื่อความหมาย เลือกโฟลเดอร์ปลายทาง แล้วกดบันทึก

ประวัติการใช้งาน (History)

เบราว์เซอร์จะบันทึกรายการเว็บไซต์ที่เคยเข้าชมพร้อมวันเวลา ทำให้ย้อนกลับไปหาหน้าเดิมได้ เปิดดูได้ด้วย Ctrl + H และสามารถลบประวัติบางรายการหรือทั้งหมดได้

แคชและคุกกี้

รายการความหมายและผลต่อการใช้งาน
แคช (Cache)ไฟล์ที่เบราว์เซอร์เก็บไว้ชั่วคราวเพื่อให้เปิดเว็บเดิมได้เร็วขึ้น หากหน้าเว็บแสดงข้อมูลเก่าผิดปกติ ให้ล้างแคชแล้วโหลดใหม่
คุกกี้ (Cookie)ข้อมูลขนาดเล็กที่เว็บไซต์ฝากไว้ในเครื่อง ใช้จำสถานะการเข้าสู่ระบบและการตั้งค่า การลบคุกกี้จะทำให้ต้องเข้าสู่ระบบใหม่

2.5 การตั้งค่าที่จำเป็นในงานธุรกิจ

  • ตั้งค่าเครื่องมือค้นหาเริ่มต้น เพื่อให้พิมพ์คำค้นในแถบที่อยู่ได้ทันที
  • ตั้งค่าหน้าเริ่มต้น ให้เปิดหน้าที่ใช้ทำงานประจำ เช่น ระบบจัดการคำสั่งซื้อ
  • จัดการรหัสผ่านที่บันทึกไว้ ตรวจสอบและลบรหัสผ่านที่ไม่ใช้ โดยเฉพาะเมื่อใช้เครื่องร่วมกับผู้อื่น
  • ตั้งค่าการดาวน์โหลด กำหนดโฟลเดอร์ปลายทางให้เป็นระเบียบ
  • เปิดใช้การซิงก์ข้อมูล เมื่อเข้าสู่ระบบด้วยบัญชี จะซิงก์บุ๊กมาร์กและการตั้งค่าไปยังอุปกรณ์อื่นได้
  • ตั้งค่าการแจ้งเตือนและป๊อปอัป ปิดการแจ้งเตือนจากเว็บไซต์ที่ไม่จำเป็นเพื่อลดการรบกวน

2.6 ปลั๊กอินเสริม (Extension)

ปลั๊กอินเสริมหรือส่วนขยาย คือโปรแกรมขนาดเล็กที่ติดตั้งเพิ่มเข้าไปในเบราว์เซอร์เพื่อเพิ่มความสามารถเฉพาะด้าน

ขั้นตอนการติดตั้ง (ตัวอย่างบน Google Chrome)

  1. เปิดเมนูของเบราว์เซอร์ เลือก "ส่วนขยาย" แล้วเลือก "ไปที่ Chrome Web Store"
  2. ค้นหาชื่อส่วนขยายที่ต้องการ
  3. ตรวจสอบชื่อผู้พัฒนา จำนวนผู้ใช้ คะแนนรีวิว และสิทธิ์ที่ขอเข้าถึง
  4. กดปุ่ม "เพิ่มใน Chrome" แล้วยืนยันการติดตั้ง
  5. ปักหมุดไอคอนไว้ที่แถบเครื่องมือเพื่อเรียกใช้ได้สะดวก

ตัวอย่างส่วนขยายที่เป็นประโยชน์ต่องานธุรกิจ

ประเภทประโยชน์ในงาน
ตัวจับภาพหน้าจอบันทึกหน้าจอคำสั่งซื้อหรือหลักฐานการโอนเงินเพื่อแนบในรายงาน
ตัวจัดการรหัสผ่านเก็บรหัสผ่านที่ปลอดภัยและกรอกอัตโนมัติ ลดการใช้รหัสผ่านซ้ำ
ตัวแปลภาษาอ่านเว็บไซต์ของคู่ค้าต่างประเทศ
ตัวตรวจการสะกดและไวยากรณ์ช่วยตรวจข้อความก่อนส่งอีเมลหรือลงโพสต์
ตัวบล็อกโฆษณาและตัวติดตามลดโฆษณารบกวนและการเก็บข้อมูลพฤติกรรมที่ไม่จำเป็น
ข้อควรระวัง ส่วนขยายบางตัวขอสิทธิ์ "อ่านและเปลี่ยนแปลงข้อมูลทั้งหมดในเว็บไซต์ที่คุณเข้าชม" ซึ่งอาจอ่านรหัสผ่านหรือข้อมูลธุรกรรมได้ ควรติดตั้งเฉพาะจากร้านค้าอย่างเป็นทางการ เลือกตัวที่มีผู้ใช้จำนวนมากและรีวิวดี ตรวจสอบสิทธิ์ที่ขอทุกครั้ง และลบส่วนขยายที่ไม่ได้ใช้ออกเป็นระยะ

ใบงานประจำหน่วยที่ 2

ใบงานที่ 1 จัดระบบเบราว์เซอร์เพื่อร้านค้าออนไลน์

  1. เปิดเว็บไซต์ที่กำหนด 5 เว็บไซต์ในแท็บแยกกัน
  2. สร้างโฟลเดอร์บุ๊กมาร์กชื่อ "ร้านค้าออนไลน์" และจัดเก็บลิงก์ทั้งหมดพร้อมตั้งชื่อให้สื่อความหมาย
  3. ล้างแคชและคุกกี้ของช่วงเวลา 1 ชั่วโมงล่าสุด
  4. บันทึกภาพหน้าจอผลการทำงานส่งท้ายคาบ

ใบงานที่ 2 ติดตั้งและประเมินปลั๊กอิน ให้ติดตั้งส่วนขยาย 1 รายการที่เป็นประโยชน์ต่อการทำงาน แล้วเขียนรายงานสั้นระบุชื่อผู้พัฒนา จำนวนผู้ใช้ สิทธิ์ที่ขอเข้าถึง ประโยชน์ที่ได้รับ และความเสี่ยงที่ควรระวัง

สรุปหน่วยที่ 2

เว็บเบราว์เซอร์เป็นประตูสู่บริการทั้งหมดบนอินเทอร์เน็ต ผู้ใช้ที่เข้าใจส่วนประกอบ ใช้คีย์ลัดจัดการแท็บ จัดบุ๊กมาร์กอย่างเป็นระบบ ดูแลแคชและคุกกี้ ตั้งค่าความปลอดภัย และเลือกติดตั้งปลั๊กอินอย่างระมัดระวัง จะทำงานได้รวดเร็วและลดความเสี่ยงด้านข้อมูลของธุรกิจ

คำถามทบทวนหน่วยที่ 2

  1. เว็บเบราว์เซอร์ทำหน้าที่อะไร และมีส่วนประกอบสำคัญอะไรบ้าง
  2. โหมดไม่ระบุตัวตนช่วยและไม่ช่วยในเรื่องใด
  3. แคชกับคุกกี้แตกต่างกันอย่างไร
  4. เหตุใดจึงควรตรวจสอบสิทธิ์ที่ส่วนขยายร้องขอก่อนติดตั้ง
  5. จงออกแบบโครงสร้างโฟลเดอร์บุ๊กมาร์กสำหรับร้านค้าออนไลน์ของตนเอง

หน่วยที่ 3 การสืบค้นข้อมูลบนอินเทอร์เน็ต

สาระสำคัญ

ข้อมูลบนอินเทอร์เน็ตมีจำนวนมหาศาลและมีทั้งข้อมูลที่ถูกต้องและไม่ถูกต้อง ผู้เรียนจึงต้องเข้าใจหลักการทำงานของเครื่องมือค้นหา รู้จักตั้งคำค้นและใช้ตัวดำเนินการขั้นสูงเพื่อให้ได้ผลลัพธ์ตรงความต้องการ ประเมินความน่าเชื่อถือของแหล่งข้อมูลได้ และบันทึกพร้อมอ้างอิงข้อมูลอย่างถูกต้อง ซึ่งเป็นทักษะที่จำเป็นต่อการตัดสินใจทางธุรกิจ

จุดประสงค์เชิงพฤติกรรม
  1. อธิบายหลักการทำงานของ Search Engine ได้
  2. ใช้เทคนิคการค้นหาข้อมูลได้
  3. ประเมินความน่าเชื่อถือของแหล่งข้อมูลได้
  4. บันทึกและอ้างอิงข้อมูลที่สืบค้นได้อย่างถูกต้อง

3.1 หลักการทำงานของ Search Engine

เครื่องมือค้นหา (Search Engine) คือระบบที่รวบรวมข้อมูลจากเว็บไซต์ทั่วโลกมาจัดทำดัชนี เพื่อให้ผู้ใช้ค้นหาได้ด้วยคำสำคัญ การทำงานแบ่งเป็น 3 ขั้นตอนหลัก

ขั้นกระบวนการรายละเอียด
1การเก็บรวบรวม (Crawling)โปรแกรมอัตโนมัติที่เรียกว่าบอทหรือสไปเดอร์ ไล่ตามลิงก์จากเว็บหนึ่งไปอีกเว็บหนึ่งเพื่อเก็บเนื้อหา
2การจัดทำดัชนี (Indexing)นำเนื้อหาที่เก็บได้มาวิเคราะห์คำสำคัญ หัวข้อ และความสัมพันธ์ แล้วจัดเก็บลงฐานข้อมูลขนาดใหญ่
3การจัดอันดับ (Ranking)เมื่อผู้ใช้ค้นหา ระบบจะเลือกหน้าเว็บที่ตรงที่สุดมาแสดง โดยพิจารณาความตรงของคำค้น คุณภาพเนื้อหา จำนวนเว็บไซต์ที่อ้างอิงถึง ความเร็วในการโหลด และประสบการณ์ผู้ใช้
สิ่งที่ควรเข้าใจ ผลลัพธ์ลำดับต้น ๆ ไม่ได้แปลว่าเป็นข้อมูลที่ถูกต้องที่สุดเสมอไป บางรายการเป็นโฆษณาที่จ่ายเงินเพื่อให้แสดงผลก่อน ผู้ใช้จึงต้องสังเกตคำว่า "ได้รับการสนับสนุน" หรือ "Sponsored" และประเมินเนื้อหาด้วยตนเอง

3.2 การตั้งคำค้น (Keyword)

หลักการตั้งคำค้นที่ดี

  • ใช้คำสำคัญ ไม่ใช้ประโยคยาว เช่น ค้นว่า ต้นทุนส่งพัสดุ 2569 แทนที่จะพิมพ์ว่า "อยากทราบว่าการส่งพัสดุในปีนี้มีต้นทุนเท่าไร"
  • ระบุให้เจาะจง เพิ่มคำที่จำกัดขอบเขต เช่น พื้นที่ ปี ประเภทสินค้า
  • เลือกภาษาให้ตรงแหล่งข้อมูล ข้อมูลเชิงเทคนิคหรือสถิติระดับสากล มักพบมากกว่าเมื่อค้นเป็นภาษาอังกฤษ
  • ปรับคำค้นซ้ำหลายรอบ หากผลไม่ตรง ให้เปลี่ยนคำหรือเพิ่มคำที่เฉพาะเจาะจงขึ้น

3.4 การประเมินความน่าเชื่อถือของแหล่งข้อมูล

ใช้หลักการตรวจสอบ 5 ประเด็น

ประเด็นคำถามที่ต้องถาม
ผู้เขียนหรือผู้เผยแพร่ใครเป็นเจ้าของข้อมูล มีตัวตนและความเชี่ยวชาญในเรื่องนี้หรือไม่
แหล่งที่มาเป็นหน่วยงานราชการ สถาบันการศึกษา หรือองค์กรที่เกี่ยวข้องโดยตรงหรือไม่
ความทันสมัยเผยแพร่เมื่อใด ข้อมูลยังใช้ได้กับปัจจุบันหรือไม่
ความถูกต้องมีการอ้างอิงแหล่งข้อมูลต้นทางหรือไม่ ตรวจสอบกับแหล่งอื่นแล้วตรงกันหรือไม่
วัตถุประสงค์เขียนเพื่อให้ความรู้ หรือเพื่อขายสินค้า หรือเพื่อชี้นำความคิด

3.6 การสืบค้นเพื่องานธุรกิจ

ภารกิจทางธุรกิจแนวทางการสืบค้น

หาผู้ผลิตหรือผู้จัดจำหน่ายใช้ site: ค้นในเว็บไซต์สมาคมการค้า และตรวจสอบการจดทะเบียนนิติบุคคล
ตรวจสอบข้อกำหนดทางกฎหมายค้นจากเว็บไซต์หน่วยงานราชการที่รับผิดชอบโดยตรงเท่านั้น

ตรวจสอบความน่าเชื่อถือของร้านค้าค้นชื่อร้านร่วมกับคำว่า "รีวิว" หรือ "โกง" และตรวจสอบเลขทะเบียนพาณิชย์

ใบงานที่ 3 ภารกิจสืบค้นข้อมูลเพื่อเปิดร้านออนไลน์

  1. เลือกสินค้า 1 ชนิดที่สนใจจะขาย
  2. สืบค้นข้อมูล 4 รายการ ได้แก่ ราคาขายเฉลี่ยในตลาด แหล่งผู้ผลิต ค่าจัดส่ง และข้อกำหนดทางกฎหมายที่เกี่ยวข้อง
  3. บันทึกผลลงตาราง โดยระบุคำค้นที่ใช้ ชื่อแหล่งข้อมูล URL วันที่สืบค้น และผลการประเมินความน่าเชื่อถือทั้ง 5 ประเด็น
  4. เขียนสรุปการตัดสินใจ 5 บรรทัด พร้อมอ้างอิงแหล่งข้อมูลตามรูปแบบที่กำหนด

เครื่องมือค้นหาทำงานด้วยการเก็บรวบรวม จัดทำดัชนี และจัดอันดับผลลัพธ์ ผู้ใช้ที่ตั้งคำค้นเป็นและใช้ตัวดำเนินการขั้นสูงจะได้ข้อมูลตรงความต้องการเร็วขึ้น แต่สิ่งที่สำคัญยิ่งกว่าคือการประเมินความน่าเชื่อถือของแหล่งข้อมูลก่อนนำไปใช้ และการบันทึกพร้อมอ้างอิงอย่างถูกต้อง เพื่อให้การตัดสินใจทางธุรกิจตั้งอยู่บนข้อมูลที่เชื่อถือได้

คำถามทบทวนหน่วยที่ 3

  1. Search Engine มีกระบวนการทำงานกี่ขั้นตอน อะไรบ้าง
  2. จงเขียนคำค้นที่ใช้ตัวดำเนินการ site: และ filetype: อย่างละ 1 ตัวอย่าง
  3. การประเมินความน่าเชื่อถือของข้อมูลพิจารณาจากประเด็นใดบ้าง
  4. เหตุใดจึงต้องกรองผลลัพธ์ตามช่วงเวลาเมื่อค้นหาข้อมูลราคาสินค้า
  5. การนำข้อมูลจากอินเทอร์เน็ตมาใช้โดยไม่อ้างอิงมีผลเสียอย่างไร

สาระสำคัญ

อีเมลเป็นช่องทางการติดต่อที่เป็นทางการที่สุดของภาคธุรกิจ และเป็นหลักฐานอ้างอิงได้ ผู้เรียนจึงต้องสร้างและตั้งค่าบัญชีอีเมลได้ รับส่งและแนบไฟล์ได้อย่างถูกต้อง เขียนอีเมลตามมารยาทธุรกิจ และเข้าใจกระบวนการทำธุรกรรมทางอิเล็กทรอนิกส์อย่างปลอดภัย ซึ่งเชื่อมโยงโดยตรงกับความน่าเชื่อถือของธุรกิจ

จุดประสงค์เชิงพฤติกรรม
  1. สร้างบัญชีและตั้งค่าอีเมลได้
  2. ปฏิบัติการรับ–ส่งอีเมลและแนบไฟล์ได้
  3. ใช้มารยาทการเขียนอีเมลธุรกิจได้
  4. ปฏิบัติการทำธุรกรรมทางอิเล็กทรอนิกส์อย่างปลอดภัยได้

4.2 การสร้างบัญชีและตั้งค่าอีเมล

ขั้นตอนการสร้างบัญชี

  1. เข้าเว็บไซต์ผู้ให้บริการอีเมล แล้วเลือกสร้างบัญชีใหม่
  2. กรอกชื่อ นามสกุล และเลือกชื่อผู้ใช้ที่เหมาะกับงานธุรกิจ
  3. ตั้งรหัสผ่านที่คาดเดายาก และยืนยันรหัสผ่านอีกครั้ง
  4. ระบุหมายเลขโทรศัพท์และอีเมลสำรองสำหรับกู้คืนบัญชี
  5. ยืนยันตัวตนตามที่ระบบกำหนด แล้วเข้าสู่ระบบ
การตั้งชื่อบัญชีเพื่องานธุรกิจ ควรใช้ชื่อจริงหรือชื่อองค์กร เช่น somchai.jaidee@gmail.com หรือ sales@shopname.co.th หลีกเลี่ยงชื่อเล่นหรือคำที่ไม่เป็นทางการ เพราะผู้รับใช้ชื่ออีเมลประเมินความน่าเชื่อถือตั้งแต่ยังไม่เปิดอ่าน

การตั้งค่าที่ควรทำหลังสร้างบัญชี

  • ตั้งลายเซ็นอัตโนมัติ ให้มีชื่อ ตำแหน่ง ชื่อร้านหรือบริษัท และช่องทางติดต่อ
  • เปิดการยืนยันตัวตนสองขั้นตอน เพื่อป้องกันการถูกเข้าถึงบัญชีโดยผู้อื่น
  • สร้างป้ายกำกับหรือโฟลเดอร์ เช่น คำสั่งซื้อ ผู้ผลิต การเงิน เพื่อจัดหมวดอีเมลอัตโนมัติด้วยตัวกรอง
  • ตั้งการตอบกลับอัตโนมัติ เมื่อไม่อยู่หรือนอกเวลาทำการ
  • ตรวจสอบพื้นที่จัดเก็บ และลบอีเมลที่มีไฟล์แนบขนาดใหญ่ที่ไม่จำเป็น

4.3 การรับ–ส่งอีเมลและการแนบไฟล์

4.5 ธุรกรรมทางอิเล็กทรอนิกส์

ธุรกรรมทางอิเล็กทรอนิกส์ (Electronic Transaction) หมายถึง การทำนิติกรรมหรือกิจกรรมทางธุรกิจโดยใช้ข้อมูลอิเล็กทรอนิกส์แทนเอกสารกระดาษ เช่น การสั่งซื้อสินค้า การชำระเงิน การออกใบเสร็จ และการลงนามในสัญญาอิเล็กทรอนิกส์

ประเภทของพาณิชย์อิเล็กทรอนิกส์

รูปแบบความหมายตัวอย่าง
B2Cธุรกิจขายให้ผู้บริโภคโดยตรงร้านค้าออนไลน์ขายสินค้าให้ลูกค้าทั่วไป
B2Bธุรกิจขายให้ธุรกิจโรงงานขายวัตถุดิบให้ร้านค้าปลีก
C2Cผู้บริโภคขายให้ผู้บริโภคการขายสินค้ามือสองผ่านแพลตฟอร์มประกาศขาย
B2Gธุรกิจทำธุรกรรมกับภาครัฐการยื่นเสนอราคาจัดซื้อจัดจ้างภาครัฐทางอิเล็กทรอนิกส์

ขั้นตอนการทำธุรกรรมซื้อขายออนไลน์

  1. ผู้ซื้อค้นหาสินค้าและตรวจสอบรายละเอียด ราคา และเงื่อนไข
  2. เพิ่มสินค้าลงตะกร้าและยืนยันคำสั่งซื้อ
  3. เลือกวิธีชำระเงินและกรอกข้อมูลผ่านหน้าชำระเงินที่ปลอดภัย
  4. ระบบยืนยันการชำระเงินและออกหลักฐานอิเล็กทรอนิกส์
  5. ผู้ขายจัดส่งสินค้าและแจ้งหมายเลขติดตามพัสดุ
  6. ผู้ซื้อรับสินค้า ตรวจสอบ และยืนยันการรับของ

ช่องทางการชำระเงินอิเล็กทรอนิกส์

ช่องทางลักษณะ
โอนผ่านแอปธนาคารสะดวก ค่าธรรมเนียมต่ำ ต้องเก็บหลักฐานการโอนทุกครั้ง
QR Code (พร้อมเพย์)สแกนจ่ายได้ทันที เหมาะกับร้านค้าขนาดเล็ก
บัตรเครดิตและบัตรเดบิตรองรับการผ่อนชำระ มีระบบคุ้มครองผู้ถือบัตร มีค่าธรรมเนียมร้านค้า
กระเป๋าเงินอิเล็กทรอนิกส์เติมเงินไว้ล่วงหน้าแล้วใช้จ่าย เหมาะกับยอดเงินไม่สูง
เก็บเงินปลายทางผู้ซื้อมั่นใจมากขึ้น แต่ผู้ขายมีความเสี่ยงจากการปฏิเสธรับของ

4.6 ความปลอดภัยในการทำธุรกรรม

  • ตรวจสอบว่าหน้าเว็บชำระเงินเป็น https:// และชื่อโดเมนถูกต้องทุกตัวอักษร
  • ไม่ทำธุรกรรมการเงินผ่าน Wi-Fi สาธารณะที่ไม่มีรหัสผ่าน
  • ไม่บอกรหัส OTP แก่ผู้ใด แม้ผู้ติดต่อจะอ้างว่าเป็นเจ้าหน้าที่ธนาคารหรือแพลตฟอร์ม
  • เก็บหลักฐานการสั่งซื้อ การชำระเงิน และการสนทนาไว้ทุกครั้ง
  • ตรวจสอบรายการเดินบัญชีอย่างสม่ำเสมอ และตั้งการแจ้งเตือนเมื่อมีรายการเคลื่อนไหว
  • ตรวจสอบตัวตนของร้านค้าจากเลขทะเบียนพาณิชย์และรีวิวจากผู้ซื้อรายอื่นก่อนโอนเงิน
กฎหมายที่เกี่ยวข้อง ประเทศไทยมีพระราชบัญญัติว่าด้วยธุรกรรมทางอิเล็กทรอนิกส์ ซึ่งรับรองให้ข้อมูลอิเล็กทรอนิกส์และลายมือชื่ออิเล็กทรอนิกส์มีผลผูกพันทางกฎหมายเช่นเดียวกับเอกสารกระดาษ นอกจากนี้ยังมีพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล ซึ่งกำหนดให้ผู้เก็บข้อมูลลูกค้าต้องขอความยินยอมและดูแลข้อมูลอย่างเหมาะสม

ใบงานประจำหน่วยที่ 4

ใบงานที่ 4 ภารกิจอีเมลมืออาชีพ

  1. สร้างหรือตั้งค่าบัญชีอีเมลให้เหมาะกับการใช้งานธุรกิจ พร้อมตั้งลายเซ็นอัตโนมัติ
  2. เขียนอีเมลขอใบเสนอราคาถึงผู้ผลิตตามสถานการณ์สมมติที่กำหนด โดยแนบไฟล์ PDF รายละเอียดความต้องการ
  3. ส่งสำเนาถึงอาจารย์ผู้สอนในช่อง Cc
  4. แลกเปลี่ยนอีเมลกับเพื่อนในชั้นเรียน แล้วประเมินตามเกณฑ์ ชื่อเรื่องชัดเจน ใช้คำสุภาพ เนื้อหาครบถ้วน แนบไฟล์ครบ และสะกดถูกต้อง

สรุปหน่วยที่ 4

อีเมลเป็นเครื่องมือสื่อสารทางการที่ใช้เป็นหลักฐานได้ การตั้งค่าบัญชีอย่างเหมาะสม การเขียนตามโครงสร้างและมารยาทที่ถูกต้อง ช่วยสร้างความน่าเชื่อถือให้ธุรกิจ ส่วนธุรกรรมทางอิเล็กทรอนิกส์มีหลายรูปแบบและหลายช่องทางชำระเงิน ผู้ใช้ต้องตรวจสอบความปลอดภัยของเว็บไซต์ รักษารหัส OTP และเก็บหลักฐานทุกครั้ง

คำถามทบทวนหน่วยที่ 4

  1. ช่อง Cc และ Bcc ต่างกันอย่างไร ควรใช้ Bcc ในกรณีใด
  2. จงอธิบายโครงสร้างของอีเมลธุรกิจที่ดีตามลำดับ
  3. หากไฟล์แนบมีขนาดเกินที่ระบบอนุญาต ควรแก้ปัญหาอย่างไร
  4. พาณิชย์อิเล็กทรอนิกส์แบบ B2B และ B2C ต่างกันอย่างไร
  5. จงยกตัวอย่างแนวปฏิบัติด้านความปลอดภัยในการชำระเงินออนไลน์มา 4 ข้อ

หน่วยที่ 5 การใช้สื่อสังคมออนไลน์เพื่อธุรกิจ

สาระสำคัญ

สื่อสังคมออนไลน์เป็นช่องทางที่ธุรกิจใช้เข้าถึงลูกค้าด้วยต้นทุนต่ำและวัดผลได้ ผู้เรียนต้องจำแนกประเภทของแพลตฟอร์มและเลือกใช้ให้ตรงกับกลุ่มเป้าหมาย สร้างและตั้งค่าบัญชีธุรกิจอย่างถูกต้อง ผลิตเนื้อหาเพื่อประชาสัมพันธ์และการตลาด รวมถึงวางแผนและวัดผลอย่างเป็นระบบ

จุดประสงค์เชิงพฤติกรรม
  1. จำแนกประเภทของสื่อสังคมออนไลน์ได้
  2. สร้างและตั้งค่าบัญชีเพื่อธุรกิจได้
  3. ผลิตเนื้อหาหรือโพสต์เพื่อประชาสัมพันธ์และการตลาดได้
  4. ประยุกต์ใช้สื่อสังคมออนไลน์ในงานธุรกิจดิจิทัลได้

5.1 ความหมายและประเภทของสื่อสังคมออนไลน์

สื่อสังคมออนไลน์ (Social Media) คือบริการบนอินเทอร์เน็ตที่เปิดให้ผู้ใช้สร้างเนื้อหา แบ่งปัน และมีปฏิสัมพันธ์กับผู้อื่นได้ โดยผู้ใช้เป็นทั้งผู้ผลิตและผู้รับสารในเวลาเดียวกัน

ประเภทตัวอย่างแพลตฟอร์มการใช้งานเชิงธุรกิจ
เครือข่ายสังคมFacebookสร้างเพจร้าน โพสต์สินค้า ตอบแชท และลงโฆษณาแบบเจาะกลุ่ม
แบ่งปันภาพและวิดีโอสั้นInstagram, TikTokนำเสนอสินค้าด้วยภาพและคลิปสั้น สร้างการรับรู้แบรนด์
วิดีโอขนาดยาวYouTubeรีวิวสินค้า สาธิตการใช้งาน และให้ความรู้เพื่อสร้างความเชี่ยวชาญ
แอปสนทนาLINE, Messengerบริการลูกค้า แจ้งสถานะคำสั่งซื้อ และส่งข้อความส่งเสริมการขาย
เครือข่ายวิชาชีพLinkedInติดต่อคู่ค้าเชิงธุรกิจและประกาศรับสมัครงาน
ข้อความสั้นX (Twitter)สื่อสารประเด็นสั้น ติดตามกระแส และชี้แจงข่าวสาร

5.2 การสร้างและตั้งค่าบัญชีธุรกิจ

บัญชีธุรกิจแตกต่างจากบัญชีส่วนตัว เพราะมีเครื่องมือสำหรับผู้ขายโดยเฉพาะ เช่น สถิติผู้เข้าชม การตั้งเวลาโพสต์ ปุ่มติดต่อ และการซื้อโฆษณา

ขั้นตอนโดยสังเขป

  1. เข้าสู่ระบบด้วยบัญชีส่วนตัว แล้วเลือกสร้างเพจหรือบัญชีธุรกิจ
  2. ตั้งชื่อร้านให้สั้น จำง่าย และสอดคล้องกับชื่อที่ใช้ในทุกช่องทาง
  3. เลือกหมวดหมู่ธุรกิจให้ตรงกับสินค้าหรือบริการ
  4. อัปโหลดภาพโปรไฟล์เป็นโลโก้ และภาพหน้าปกที่สื่อถึงสินค้า
  5. กรอกข้อมูลติดต่อให้ครบ ได้แก่ ที่อยู่ เบอร์โทรศัพท์ อีเมล เวลาทำการ และลิงก์ร้านค้า
  6. เขียนคำอธิบายร้านที่ระบุว่าขายอะไร ให้บริการใคร และมีจุดเด่นอย่างไร
  7. ตั้งค่าข้อความตอบกลับอัตโนมัติและคำถามที่พบบ่อย
  8. เพิ่มผู้ดูแลเพจตามบทบาทหน้าที่ และเปิดการยืนยันตัวตนสองขั้นตอน

5.3 การผลิตเนื้อหาเพื่อการตลาด

ประเภทของเนื้อหาที่ควรมี

ประเภทเนื้อหาวัตถุประสงค์ตัวอย่าง
ให้ความรู้สร้างความเชี่ยวชาญและความไว้วางใจวิธีเลือกขนาดสินค้าให้เหมาะกับการใช้งาน
นำเสนอสินค้าอธิบายคุณสมบัติและราคาภาพสินค้าพร้อมรายละเอียดและราคาที่ชัดเจน
สร้างความน่าเชื่อถือลดความลังเลของผู้ซื้อรีวิวจากลูกค้าจริง ภาพการจัดส่ง ใบรับรองสินค้า
ส่งเสริมการขายกระตุ้นการตัดสินใจซื้อส่วนลดตามช่วงเวลา ของแถม จัดส่งฟรีเมื่อครบยอด
สร้างการมีส่วนร่วมเพิ่มการเข้าถึงและผู้ติดตามคำถามชวนตอบ กิจกรรมร่วมสนุก แบบสำรวจความเห็น

องค์ประกอบของโพสต์ที่ดี

  1. ภาพหรือวิดีโอที่ชัดเจน ถ่ายในที่ที่มีแสงเพียงพอ เห็นสินค้าชัด และมีสัดส่วนเหมาะกับแพลตฟอร์ม
  2. ประโยคเปิดที่ดึงความสนใจ ใน 1–2 บรรทัดแรก เพราะผู้ใช้เลื่อนผ่านอย่างรวดเร็ว
  3. เนื้อหาที่ตอบคำถามของลูกค้า ได้แก่ สินค้าคืออะไร แก้ปัญหาอะไร ราคาเท่าไร สั่งซื้ออย่างไร
  4. ข้อความเชิญชวนให้ลงมือทำ (Call to Action) เช่น ทักแชทเพื่อสั่งซื้อ กดลิงก์ในโปรไฟล์
  5. แฮชแท็กที่เกี่ยวข้อง จำนวนพอเหมาะ ตรงกับสินค้าและกลุ่มเป้าหมาย
ข้อควรระวังด้านเนื้อหา ห้ามโฆษณาเกินจริงหรือกล่าวอ้างสรรพคุณที่พิสูจน์ไม่ได้ ห้ามนำภาพหรือข้อความของผู้อื่นมาใช้โดยไม่ได้รับอนุญาต และต้องขออนุญาตลูกค้าก่อนนำภาพหรือข้อความรีวิวมาเผยแพร่ เพื่อไม่ให้ขัดต่อกฎหมายคุ้มครองข้อมูลส่วนบุคคล

ปฏิทินเนื้อหา (Content Calendar)

วันประเภทเนื้อหาตัวอย่างหัวข้อ
จันทร์ให้ความรู้3 วิธีเลือกสินค้าให้เหมาะกับการใช้งาน

อัตราการเปลี่ยนเป็นยอดขายสัดส่วนผู้ที่ทักแชทแล้วสั่งซื้อจริง ใช้วัดประสิทธิภาพการปิดการขาย

5.5 การประยุกต์ใช้ในงานธุรกิจดิจิทัล

  • การบริการลูกค้า กำหนดเวลาตอบกลับมาตรฐาน จัดทำคำตอบสำเร็จรูปสำหรับคำถามที่พบบ่อย และบันทึกข้อร้องเรียนเพื่อปรับปรุง
  • การขายผ่านไลฟ์ วางลำดับการนำเสนอสินค้า เตรียมโปรโมชันเฉพาะช่วงไลฟ์ และมีผู้ช่วยสรุปคำสั่งซื้อ
  • การร่วมมือกับผู้มีอิทธิพลทางความคิด เลือกผู้ที่มีกลุ่มผู้ติดตามตรงกับสินค้า และตกลงขอบเขตงานเป็นลายลักษณ์อักษร
  • การรับฟังเสียงลูกค้า ติดตามความคิดเห็นและรีวิวเพื่อพัฒนาสินค้าและบริการ
  • การจัดการภาวะวิกฤต เมื่อเกิดข้อร้องเรียนต่อสาธารณะ ควรตอบอย่างสุภาพ รับผิดชอบตามข้อเท็จจริง และเสนอแนวทางแก้ไขอย่างรวดเร็ว

ใบงานประจำหน่วยที่ 5

ใบงานที่ 5 สร้างบัญชีธุรกิจ ให้สร้างเพจหรือบัญชีธุรกิจสมมติ 1 บัญชี ตั้งค่าข้อมูลร้านให้ครบถ้วน พร้อมภาพโปรไฟล์และคำอธิบายร้าน

ใบงานที่ 6 ผลิตเนื้อหาเพื่อการตลาด ให้จัดทำโพสต์ 3 ชิ้น ประกอบด้วยเนื้อหาให้ความรู้ นำเสนอสินค้า และส่งเสริมการขาย พร้อมจัดทำปฏิทินเนื้อหา 1 สัปดาห์ และระบุตัวชี้วัดที่จะใช้ประเมินผล

สรุปหน่วยที่ 5

สื่อสังคมออนไลน์มีหลายประเภทและเหมาะกับกลุ่มเป้าหมายต่างกัน การใช้บัญชีธุรกิจที่ตั้งค่าครบถ้วน ผลิตเนื้อหาหลากหลายอย่างสม่ำเสมอ วางแผนด้วยปฏิทินเนื้อหา และวัดผลด้วยตัวชี้วัดที่ชัดเจน จะทำให้ธุรกิจเข้าถึงลูกค้าได้มากขึ้นและปรับปรุงการทำงานได้อย่างมีหลักฐานรองรับ

คำถามทบทวนหน่วยที่ 5

  1. สื่อสังคมออนไลน์มีกี่ประเภท จงยกตัวอย่างพร้อมการใช้งานเชิงธุรกิจ
  2. บัญชีธุรกิจมีข้อได้เปรียบกว่าบัญชีส่วนตัวอย่างไร
  3. องค์ประกอบของโพสต์ที่ดีมีอะไรบ้าง
  4. ตัวชี้วัด Reach และ Engagement ต่างกันอย่างไร
  5. หากร้านได้รับข้อร้องเรียนบนหน้าเพจสาธารณะ ควรดำเนินการอย่างไร

หน่วยที่ 6 ความปลอดภัยในการใช้อินเทอร์เน็ต

สาระสำคัญ

การใช้อินเทอร์เน็ตในงานธุรกิจมีความเสี่ยงจากภัยคุกคามหลายรูปแบบ ทั้งการหลอกลวง โปรแกรมประสงค์ร้าย และการรั่วไหลของข้อมูล ผู้เรียนจึงต้องรู้จักประเภทของภัยคุกคาม วิธีป้องกันและตั้งค่าความปลอดภัย การจัดการรหัสผ่านและการยืนยันตัวตน รวมถึงจริยธรรมและกฎหมายที่เกี่ยวข้อง เพื่อนำไปปฏิบัติจริงในงานธุรกิจดิจิทัล

จุดประสงค์เชิงพฤติกรรม
  1. ระบุประเภทภัยคุกคามบนอินเทอร์เน็ตได้
  2. อธิบายวิธีป้องกันและตั้งค่าความปลอดภัยได้
  3. อธิบายจริยธรรมและกฎหมายที่เกี่ยวข้องได้
  4. ประยุกต์แนวปฏิบัติด้านความปลอดภัยในงานธุรกิจดิจิทัลได้

6.1 ภัยคุกคามบนอินเทอร์เน็ต

ภัยคุกคามลักษณะตัวอย่างที่พบบ่อย
ฟิชชิง (Phishing)การหลอกให้กรอกข้อมูลสำคัญผ่านอีเมลหรือเว็บไซต์ปลอมที่ทำเลียนแบบของจริงอีเมลแจ้งว่าบัญชีถูกระงับ พร้อมลิงก์ให้กดยืนยันรหัสผ่าน
มัลแวร์ (Malware)โปรแกรมประสงค์ร้ายที่ติดตั้งลงเครื่องเพื่อขโมยข้อมูลหรือทำลายระบบไฟล์แนบหรือโปรแกรมละเมิดลิขสิทธิ์ที่ดาวน์โหลดจากแหล่งไม่น่าเชื่อถือ
แรนซัมแวร์ (Ransomware)มัลแวร์ที่เข้ารหัสไฟล์ทั้งหมดแล้วเรียกค่าไถ่ไฟล์งานทั้งเครื่องเปิดไม่ได้ และมีข้อความเรียกเงิน
สแปม (Spam)ข้อความโฆษณาจำนวนมากที่ไม่ได้ร้องขออีเมลโฆษณาที่ส่งซ้ำ ๆ และอาจแฝงลิงก์อันตราย
การหลอกลวงทางสังคม (Social Engineering)การใช้จิตวิทยาหลอกให้เหยื่อเปิดเผยข้อมูลหรือโอนเงินแอบอ้างเป็นเจ้าหน้าที่ธนาคารหรือขนส่ง โทรมาขอ OTP
บัญชีปลอมการสร้างบัญชีเลียนแบบร้านค้าหรือบุคคลเพื่อหลอกลูกค้าเพจปลอมที่ใช้ชื่อและภาพเหมือนร้านจริง แต่เปลี่ยนเลขบัญชีรับเงิน
ข้อมูลรั่วไหล (Data Breach)ข้อมูลลูกค้าหรือข้อมูลภายในถูกเข้าถึงโดยไม่ได้รับอนุญาตรายชื่อและเบอร์โทรลูกค้าหลุดออกไปยังบุคคลภายนอก

วิธีสังเกตอีเมลหรือลิงก์หลอกลวง

  1. ตรวจชื่อโดเมนของผู้ส่งอย่างละเอียด มักสะกดใกล้เคียงของจริง เช่น เปลี่ยนตัวอักษรหรือเพิ่มคำต่อท้าย
  2. สังเกตการเร่งรัดให้ดำเนินการทันที เช่น แจ้งว่าบัญชีจะถูกปิดใน 24 ชั่วโมง
  3. ระวังไฟล์แนบหรือลิงก์ที่ไม่ได้คาดหมาย
  4. นำเมาส์ไปวางเหนือลิงก์เพื่อดู URL ปลายทางจริงก่อนคลิก
  5. หน่วยงานที่ถูกต้องจะไม่ขอรหัสผ่านหรือรหัส OTP ทางอีเมลหรือโทรศัพท์
  6. หากสงสัย ให้ติดต่อหน่วยงานนั้นผ่านช่องทางทางการที่ค้นหาเอง ไม่ใช่ช่องทางในอีเมลฉบับนั้น

6.2 การป้องกันและตั้งค่าความปลอดภัย

มาตรการรายละเอียดการปฏิบัติ
ปรับปรุงซอฟต์แวร์ให้ทันสมัยอัปเดตระบบปฏิบัติการ เบราว์เซอร์ และแอปพลิเคชันอย่างสม่ำเสมอ เพื่อปิดช่องโหว่
ติดตั้งโปรแกรมป้องกันไวรัสเปิดการสแกนอัตโนมัติและอัปเดตฐานข้อมูลไวรัสเป็นประจำ
สำรองข้อมูลสำรองข้อมูลสำคัญอย่างน้อย 2 ชุด โดยเก็บไว้คนละที่ เช่น ฮาร์ดดิสก์ภายนอกและบริการคลาวด์
ใช้เครือข่ายที่ปลอดภัยหลีกเลี่ยงการทำธุรกรรมผ่าน Wi-Fi สาธารณะ และตั้งรหัสผ่าน Wi-Fi ของร้านให้คาดเดายาก
กำหนดสิทธิ์การเข้าถึงให้พนักงานเข้าถึงเฉพาะข้อมูลที่จำเป็นต่อหน้าที่ และยกเลิกสิทธิ์ทันทีเมื่อพ้นหน้าที่
ตรวจสอบก่อนติดตั้งดาวน์โหลดโปรแกรมจากเว็บไซต์ทางการหรือร้านค้าแอปที่เชื่อถือได้เท่านั้น

6.3 การจัดการรหัสผ่านและการยืนยันตัวตน

หลักการตั้งรหัสผ่านที่ปลอดภัย

  • มีความยาวอย่างน้อย 12 ตัวอักษร ประกอบด้วยตัวพิมพ์ใหญ่ ตัวพิมพ์เล็ก ตัวเลข และอักขระพิเศษ
  • ไม่ใช้ข้อมูลที่คาดเดาได้ เช่น วันเกิด ชื่อเล่น เบอร์โทรศัพท์ หรือคำว่า 123456
  • ไม่ใช้รหัสผ่านเดียวกันกับหลายบริการ เพราะหากบริการหนึ่งข้อมูลรั่ว บัญชีอื่นจะถูกเข้าถึงตามไปด้วย
  • ใช้โปรแกรมจัดการรหัสผ่านช่วยสร้างและจดจำรหัสผ่านที่ซับซ้อน
  • เปลี่ยนรหัสผ่านทันทีเมื่อสงสัยว่ามีการรั่วไหล

การยืนยันตัวตนสองขั้นตอน (Two-Factor Authentication)

เป็นการเพิ่มชั้นความปลอดภัยโดยนอกจากรหัสผ่านแล้ว ยังต้องยืนยันด้วยสิ่งที่ผู้ใช้มีหรือเป็น เช่น รหัสจากแอปยืนยันตัวตน รหัส OTP ทางข้อความ หรือลายนิ้วมือ ทำให้แม้รหัสผ่านรั่วไหล ผู้ไม่ประสงค์ดีก็ยังเข้าบัญชีไม่ได้ ควรเปิดใช้กับบัญชีสำคัญทุกบัญชี ได้แก่ อีเมลหลัก บัญชีธนาคาร บัญชีร้านค้า และเพจธุรกิจ

6.4 จริยธรรมและกฎหมายที่เกี่ยวข้อง

จริยธรรมในการใช้อินเทอร์เน็ต

  • ไม่เผยแพร่ข้อมูลเท็จหรือข้อมูลที่ยังไม่ได้ตรวจสอบ
  • ไม่ละเมิดสิทธิ์และความเป็นส่วนตัวของผู้อื่น
  • ไม่นำผลงานของผู้อื่นมาใช้โดยไม่อ้างอิงหรือไม่ได้รับอนุญาต
  • ไม่ใช้ถ้อยคำหยาบคายหรือสร้างความเกลียดชัง
  • เคารพกฎกติกาของแต่ละแพลตฟอร์มและชุมชนออนไลน์
  • ใช้ทรัพยากรของหน่วยงานหรือสถานประกอบการเพื่อประโยชน์ในงานเท่านั้น

กฎหมายสำคัญที่เกี่ยวข้อง

กฎหมายสาระสำคัญที่ผู้ประกอบการต้องทราบ
พระราชบัญญัติว่าด้วยการกระทำความผิดเกี่ยวกับคอมพิวเตอร์ห้ามเข้าถึงระบบหรือข้อมูลของผู้อื่นโดยมิชอบ ห้ามนำเข้าข้อมูลเท็จที่ก่อความเสียหาย และห้ามเผยแพร่ข้อมูลที่ผิดกฎหมาย
พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคลการเก็บ ใช้ และเปิดเผยข้อมูลส่วนบุคคลของลูกค้าต้องมีฐานทางกฎหมายหรือได้รับความยินยอม และต้องมีมาตรการรักษาความปลอดภัยของข้อมูล
พระราชบัญญัติว่าด้วยธุรกรรมทางอิเล็กทรอนิกส์รับรองผลทางกฎหมายของข้อมูลและลายมือชื่ออิเล็กทรอนิกส์
พระราชบัญญัติลิขสิทธิ์การนำภาพ ข้อความ เพลง หรือวิดีโอของผู้อื่นมาใช้โดยไม่ได้รับอนุญาต ถือเป็นการละเมิดลิขสิทธิ์
กฎหมายคุ้มครองผู้บริโภคและการโฆษณาห้ามโฆษณาเป็นเท็จหรือเกินความจริง และต้องแสดงราคาและเงื่อนไขให้ชัดเจน

6.5 แนวปฏิบัติด้านความปลอดภัยในงานธุรกิจ

รายการตรวจสอบความปลอดภัยสำหรับร้านค้าออนไลน์
ลำดับรายการตรวจสอบ
1บัญชีอีเมลและบัญชีร้านค้าเปิดการยืนยันตัวตนสองขั้นตอนครบทุกบัญชี
2รหัสผ่านแต่ละบริการไม่ซ้ำกัน และเก็บในโปรแกรมจัดการรหัสผ่าน
3สำรองข้อมูลคำสั่งซื้อและรายชื่อลูกค้าอย่างน้อยสัปดาห์ละครั้ง
4ผู้ดูแลเพจมีเฉพาะผู้ที่จำเป็น และทบทวนรายชื่อทุกเดือน
5ไม่ใช้เครื่องคอมพิวเตอร์ของร้านดาวน์โหลดโปรแกรมจากแหล่งที่ไม่น่าเชื่อถือ
6ตรวจสอบเลขบัญชีรับเงินในทุกช่องทางว่าตรงกับบัญชีของร้านจริง
7แจ้งลูกค้าถึงช่องทางติดต่อทางการ เพื่อลดความเสี่ยงจากเพจปลอม
8จัดเก็บข้อมูลลูกค้าเท่าที่จำเป็น และลบข้อมูลที่ไม่ใช้แล้ว
9อบรมพนักงานให้รู้จักสังเกตอีเมลและข้อความหลอกลวง
10มีแผนรับมือเมื่อเกิดเหตุ ได้แก่ เปลี่ยนรหัสผ่าน แจ้งผู้เกี่ยวข้อง และแจ้งความ

ขั้นตอนเมื่อสงสัยว่าถูกโจมตีหรือข้อมูลรั่วไหล

  1. ตัดการเชื่อมต่ออินเทอร์เน็ตของเครื่องที่สงสัยทันที
  2. เปลี่ยนรหัสผ่านบัญชีสำคัญจากเครื่องที่ปลอดภัย
  3. ตรวจสอบรายการเข้าสู่ระบบและอุปกรณ์ที่เชื่อมต่อบัญชี แล้วลบอุปกรณ์แปลกปลอมออก
  4. สแกนไวรัสและกู้คืนข้อมูลจากไฟล์สำรอง
  5. แจ้งลูกค้าและผู้เกี่ยวข้องหากข้อมูลของพวกเขาได้รับผลกระทบ
