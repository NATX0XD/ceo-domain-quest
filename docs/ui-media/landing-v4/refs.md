# Landing v4 visual research

1. **Duolingo** uses a clear mascot-led promise, bite-sized progress cues, and friendly rewards so the page feels like an invitation to start a habit, not a product brochure: https://www.duolingo.com/
2. **Brawl Stars / Supercell** treats the landing as a game portal: bold character moments, high-contrast promotional panels, clear mode CTAs, and motion-ready art keep the eye moving between play beats: https://supercell.com/en/games/brawlstars/
3. **Pokémon** mixes a strong hero moment with news/event modules and collectible character imagery; varied modules make the page feel alive instead of one long repeated card grid: https://www.pokemon.com/
4. **Animal Crossing: New Horizons** leans on a complete world scene, layered landscape depth, seasonal atmosphere, and small character/object discoveries to make scrolling feel like entering a place: https://animalcrossing.nintendo.com/new-horizons/
5. **Genshin Impact** uses cinematic landscape continuity, character reveals, and sticky-feeling story beats with strong download/play actions; scenery should carry the section transitions: https://genshin.hoyoverse.com/en-us/home
6. **BetterEdu** keeps the education promise prominent, then supports it with friendly feature proof and AI-assistant framing; learning pages benefit from a concrete “what happens next” path: https://www.betteredu.org/
7. Shared pattern: use a foreground/midground/background stack, with props that drift at different speeds and section dividers that visually flow from sea to sand to island.
8. Shared pattern: reveal cards and numbers on entry, but reserve looping motion for small props/mascot moments so the page still feels calm and readable.
9. Shared pattern: add hover/tap feedback to cards, buttons, and map points; on mobile, make the same interactions work through focus and tap rather than hover-only.
10. Landing v4 direction: a purple Dome world that progresses sky → beach → island → sunset/night, with a visible path and recurring floating signs/coins to make the scroll feel like one quest.
