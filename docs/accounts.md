# เตรียมบัญชีผู้ทดสอบ

เจ้าของระบบสร้างบัญชีล่วงหน้าได้ด้วยสคริปต์นี้ โดยสคริปต์ใช้ `SUPABASE_URL` และ `SUPABASE_SERVICE_ROLE_KEY` จาก `.env.local` หรือ environment ของ Vercel และจะไม่แสดงค่าเหล่านี้ใน terminal

## 1. เตรียม CSV

บรรทัดแรกต้องเป็นหัวตารางนี้พอดี:

```csv
role,name,email_or_nickname,room_code
teacher,ครูทดลอง,kru-test@example.ac.th,ABCD23
student,นักเรียนหนึ่ง,น้องหนึ่ง,ABCD23
```

`role` ใช้ `teacher` หรือ `student`; อีเมลใช้เฉพาะแถวครู ส่วนแถวนักเรียนใช้ชื่อเล่น 1–40 ตัวอักษรและต้องไม่ซ้ำในห้องเดียวกัน รหัสห้องต้องเป็น 6 ตัวตามกติกาของระบบ แถวครูจะสร้างห้องตาม `room_code` ถ้ายังไม่มีห้องนั้น แถวนักเรียนต้องอ้างห้องที่มีอยู่แล้วหรือห้องครูที่อยู่ก่อนหน้าในไฟล์เดียวกัน

## 2. ตรวจและสร้าง

ตรวจ CSV โดยไม่เขียนฐานข้อมูล:

```bash
npx tsx scripts/create-accounts.ts accounts.csv --dry-run
```

สร้างจริง (อย่ารันกับ cloud จนกว่าจะตรวจ environment และได้รับอนุมัติ):

```bash
npx tsx scripts/create-accounts.ts accounts.csv
npx tsx scripts/create-accounts.ts accounts.csv --output ./accounts-for-testers.csv
```

ไฟล์ผลลัพธ์เริ่มต้นอยู่ที่ `~/Desktop/ceo-domain-quest-accounts.csv` และถูกตั้งสิทธิ์ `600` มีรหัสผ่านชั่วคราวของครูและ PIN 4 หลักของนักเรียน เจ้าของควรเก็บไฟล์นี้ไว้เฉพาะตนเองและลบทิ้งเมื่อแจกข้อมูลครบแล้ว สคริปต์ไม่ log credential และไม่เขียนผลลัพธ์เมื่อใช้ `--dry-run`

## 3. แจกข้อมูลให้ผู้ทดสอบ

ส่งเฉพาะแถวของแต่ละคนผ่านช่องทางส่วนตัว ครูเข้าสู่ระบบด้วยอีเมลกับรหัสผ่านชั่วคราว แล้วเปลี่ยนชื่อที่แสดงและรหัสผ่านได้ที่ `ตั้งค่า → บัญชีของฉัน` นักเรียนเข้าห้องด้วยรหัสห้อง ชื่อเล่น และ PIN จากไฟล์ แล้วเปิด `โปรไฟล์ → บัญชีของฉัน` เพื่อเปลี่ยนชื่อเล่นหรือ PIN ได้เอง

การเปลี่ยนชื่อเล่นไม่ทำให้ความคืบหน้าหาย และ PIN ใหม่ใช้เข้าห้องครั้งถัดไปได้ ระบบจะแสดงคำเตือนว่า **“ใช้ชื่อใหม่นี้ตอนเข้าห้องครั้งถัดไป”**
