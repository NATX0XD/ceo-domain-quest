# UX brief รอบ 2 — ให้รู้สึกเป็นแอป ไม่ใช่เว็บย่อจอ และหน้าตาตรงกับแบบของแต่ละด่าน

## สิ่งที่เจ้าของงานไม่เอา
- หน้าตาแบบ Flow S01-S20 เดิม (การ์ดขาวแบน ๆ เรียงลงมาแบบหน้าเว็บ) — docs/mission-3/images/flow-*.png
- หน้าเว็บที่แค่ responsive: scroll ทั้งหน้า หัวข้อซ้อนหลายชั้น ลิงก์ขีดเส้นใต้ ตัวหนังสือแน่น

## หลัก "แอป" (ใช้ทุกจอของ learn path และเกมลงมือทำ)
1. เต็มจอ `h-dvh` ไม่มี scroll ทั้งหน้า ถ้าเนื้อหายาวให้ scroll เฉพาะกล่องกลาง
2. แถบบนแบบแอป สูง 56px: ปุ่มย้อนกลับ (ไอคอน), ชื่อด่านสั้น, HUD ขวา (ดาว/ความคืบหน้า) ไม่มีลิงก์ขีดเส้นใต้
3. ปุ่มหลักอยู่ใน dock ล่างติดจอ (safe-area-inset-bottom) ปุ่มเดียวเด่น ปุ่มรองเป็นไอคอนหรือ ghost
4. เปลี่ยนขั้นด้วย transition แบบแอป ใช้ไลบรารี `motion` ที่มีอยู่แล้ว (motion/react): ไปข้างหน้า slide-in จากขวา ย้อนกลับ slide จากซ้าย 220-280ms, เปิดแผ่น/การ์ด = spring scale+fade, ปิด = fade-down; เคารพ prefers-reduced-motion
5. ลูกเล่น: ปุ่มกดยุบ scale .96, ตอบถูก = เด้ง + ประกายดาว/คอนเฟตตีเล็ก ๆ, ยังไม่ใช่ = สั่นเบา ๆ (shake) ไม่ใช้สีแดงจัด, แชตมี typing indicator 3 จุดก่อนข้อความขึ้น, โดมขยับหายใจ (idle float) และเปลี่ยนอารมณ์ตามผล, ตัวนับคะแนนวิ่งขึ้น (count-up), progress bar ไหลลื่น, `navigator.vibrate?.(10)` ตอนกดตัวเลือกบนมือถือ
6. ตัวอักษร: หัวเรื่อง 22-24px หนา, เนื้อ 16-17px, บรรทัด 1.6, ระยะขอบ 16-20px, การ์ดมุม 20-24px, เงานุ่ม
7. เปลี่ยนวิธีเรียน / ข้ามไปทำภารกิจ ย้ายไปไว้ในเมนู (ปุ่ม ⋯ บนแถบบน → bottom sheet) ไม่ใช่ลิงก์ลอย
