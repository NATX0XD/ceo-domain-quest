## หมายเหตุจากการตรวจ

- ในรอบนี้ Typhoon เป็นเจ้าที่ตอบจริงทุกครั้งที่ข้อความถึงโมเดล (เจ้าแรกในลูกโซ่ และตอบทันงบ 5 วินาที)
- แถว FORCED เรียก askDome ตรง (ไม่ผ่านเซิร์ฟเวอร์ที่ใช้งานอยู่) ด้วย env ปลอม: Typhoon คีย์เสีย + Gemini จริง = ล้ม Typhoon แล้วสลับไป Gemini ได้ ทั้งสองคีย์เสีย หรือไม่มีคีย์ = โดมตอบด้วยกฎ ไม่ error
- Gemini ตอบช้าในวันตรวจ (~12 วินาที วัดตรง) จึงต้องใช้ timeout 20 วินาทีในแถว FORCED ที่งบเดิม 5 วินาที Gemini จะหมดเวลาและตกไปกฎ ควรวัดความเร็ว Gemini ใหม่ก่อนพึ่งเป็นตัวสำรองในห้องเรียน
- ข้อมูลส่วนตัว (เบอร์โทร) ถูกตัวกรอง E-11 ของเส้นทางเดิมตีกลับ HTTP 422 ก่อนถึงโดม (ไม่ส่งเข้าโมเดล ไม่บันทึกแชต) ตัวจัดหมวดของโดมยังมีด่านที่สองสำหรับคำถามขอ/ให้ข้อมูลส่วนตัวที่ตัวกรองไม่จับ (มีเทสต์ใน components/server/dome-brain.test.ts)
- คำถามต่อเนื่องที่ให้ตัวอย่างร้านกาแฟเคยถูกตัวกันหัวข้อทิ้งเป็นบางรอบ (โมเดลยกชื่อนามสกุลของภารกิจถัดไปมาเป็นตัวอย่าง) โดมจึงตอบด้วยกฎแทน นี่คือพฤติกรรมที่ตั้งใจ (ปลอดภัยก่อน) แต่ทำให้บางรอบไม่ได้คำตอบจาก AI ดู log `[dome] ใช้กฎแทน AI: ...` ในเทอร์มินัลเซิร์ฟเวอร์เพื่อดูเหตุผล
