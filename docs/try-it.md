# ลองเล่นเองบนเครื่องตัวเอง (UAT)

เอกสารนี้สำหรับ **เปิดเล่นดูของจริงบนเครื่องตัวเอง** ไม่ใช่เซิร์ฟเวอร์จริง
รหัสผ่านในนี้ตั้งให้ง่ายไว้ตั้งใจ ห้ามใช้ชุดนี้ตอนขึ้นคลาวด์

ตรวจจริงเมื่อ 30 กันยายน 2569 · **ตรวจซ้ำทีละบรรทัดอีกรอบตอนเช้าวันเดียวกัน หลังทีมแก้ของใหม่ลงไปเยอะ — เดินครบวงผ่าน**
ของใหม่ที่เพิ่งเพิ่มเข้ามารอบล่าสุด อ่านสรุปสั้น ๆ ได้ที่ข้อ 9 ท้ายเอกสาร

---

## 1. สั่งอะไรให้ระบบขึ้น

เปิด Terminal ที่โฟลเดอร์โปรเจกต์ แล้วสั่งตามลำดับนี้

```bash
npm install            # ครั้งแรกครั้งเดียว
npm run db:start       # ฐานข้อมูล Supabase บนเครื่อง
npm run seed:uat       # สร้างครู + ห้อง + นักเรียนหุ่น 6 คน
npm run dev            # เปิดเว็บ
```

> **ห้ามสั่ง `npm run db:reset`** — คำสั่งนั้นล้างฐานข้อมูลทั้งเครื่อง คนอื่นที่กำลังทดสอบจะหลุดทั้งหมด
> ถ้าอยากเริ่มใหม่ ใช้ `npm run seed:uat` (ข้อ 8) ซึ่งล้างแค่ห้อง UAT777 ของตัวเอง

ถ้า `npm run dev` บอกว่าพอร์ต 3000 ถูกใช้อยู่แล้ว แปลว่ามีคนเปิดไว้ให้แล้ว ข้ามข้อนี้ไปเลย

## 4. รหัสห้องคืออะไร

**`UAT777`** — ตั้งไว้คงที่ รันสคริปต์ซ้ำกี่ครั้งรหัสก็ยังเป็นตัวนี้

ในห้องมีนักเรียนหุ่น 6 คน ความคืบหน้าไม่เท่ากัน เพื่อให้ทุกหน้าจอมีของให้ดูจริง

| ชื่อเล่น | ร้าน | สิ่งที่มีให้ดู |
|---|---|---|
| อาร์ม | อาร์มเกมเซ็นเตอร์ | คนเก่ง ผ่านครบ 4 ภารกิจ ครูตรวจงานจบแล้ว · งานชิ้นนี้ถูกปักหมุดขึ้นจอหน้าห้อง |
| มะลิ | มะลิเบเกอรี่ | คนกลาง ผ่าน 2 ภารกิจ กำลังทำภารกิจที่ 3 · เคยสลับช่องทางเรียนเอง |
| ต้นกล้า | ต้นกล้าซ่อมมือถือ | คนช้า **กดขอครู** (ขึ้นธงบนแผงครู) · เคยกดข้ามภารกิจ |
| ปูเป้ | ปูเป้ดอกไม้สด | ขอคำใบ้เยอะ ใช้คำใบ้เต็มทุกภารกิจ |
| ฟ้าใส | ฟ้าใสเสื้อผ้ามือสอง | **ส่งงานแล้วรอครูตรวจ** อยู่ในคิว "งานที่รอตรวจ" |
| บีม | บีมกาแฟดริป | **ครูตีกลับให้แก้** หน้าเด็กจะขึ้นว่าต้องแก้ด้านไหนและส่งใหม่ได้ |

PIN ของหุ่นทุกคนคือ **`1234`** — อยากดูว่าจอเด็กแต่ละแบบเห็นอะไร ให้เข้าด้วยชื่อเล่นข้างบนคู่กับ PIN นี้ (วิธีอยู่ข้อ 5 ตอนท้าย)

## 5. เข้าเป็นนักเรียนยังไง

**ที่นั่งว่างเตรียมไว้ให้เล่นเองแล้ว** ห้องนี้ยังไม่มีใครใช้ชื่ออื่นนอกจาก 6 ชื่อข้างบน

1. เปิด http://localhost:3000/join?code=UAT777 (หรือสแกน QR จากจอหน้าห้อง)
2. พิมพ์ชื่อเล่นอะไรก็ได้ที่ **ไม่ซ้ำ** 6 ชื่อข้างบน เช่น `เจ้าของ`
3. ตั้งรหัส 4 หลัก แนะนำ **`1111`** (จำง่าย ไม่ชนกับ PIN ของหุ่น)
4. กดเข้าห้อง → เข้าหน้า **แนะนำเรื่อง** ต่อด้วยตั้งค่าร้าน แล้วเดินตามเกมได้เลย

**สามอย่างที่เพิ่งเพิ่มมา ลองกดดูได้ตอนเล่นเป็นนักเรียน**

| ของใหม่ | กดที่ไหน |
|---|---|
| **ขอเพื่อนช่วย** ถ้าติดแล้วอยากให้เพื่อนในห้องมาช่วยคิด | ในหน้าภารกิจ (เช่น `/mission/m1`) มีกล่องขอเพื่อนช่วยอยู่ท้ายหน้า · ถ้าไม่มีเพื่อนว่างจะได้การ์ดคำถามให้คิดเองก่อน แล้วเรียกครูได้ |
| **ขอเปลี่ยนแผน** ขอลดความยาก ขอเปลี่ยนวิธีเรียน ขอข้ามด่าน หรือขอเวลาเพิ่ม | ในหน้าภารกิจเหมือนกัน · กดส่งแล้วคำขอจะไปโผล่บนแผงห้องเรียนสดของครูทันที ครูกดตอบได้ (ดูข้อ 6) |
| **เช็กว่าชื่อเว็บนี้ยังว่างไหม** ก่อนยื่นจริง | หน้ายื่นป้ายร้าน `/station-b` · พิมพ์ชื่อแล้วระบบบอกว่าชื่อถูกจองไปแล้วหรือยัง พร้อมเสนอชื่อใกล้เคียงให้เลือก (ลองพิมพ์ `shop` ดู จะเห็นว่าถูกจองแล้วและได้ชื่อใกล้เคียงมา 3 ชื่อ) |

**ปิดแท็บแล้วอยากกลับเข้ามาที่เดิม** ให้เปิดลิงก์เดิม กดปุ่ม **เคยเข้าแล้ว ย้ายเครื่อง** แล้วใส่ชื่อเล่นเดิมคู่กับรหัส 4 หลักที่ตั้งไว้ (`1111`)
สวมรอยเป็นหุ่นก็ทางเดียวกัน ใส่ชื่อเล่นของหุ่นคู่กับ PIN `1234`

> รหัส 4 หลักไม่ใช่รหัสผ่านหลัก ตัวที่ระบุตัวตนจริงคือคุกกี้ที่เซิร์ฟเวอร์ออกให้ รหัสนี้มีไว้กรณีย้ายเครื่องหรือล้างเบราว์เซอร์เท่านั้น

## 6. ครูต้องกดอะไรก่อนนักเรียนถึงเล่นได้

**สคริปต์กดไว้ให้แล้วทั้งหมด** ตื่นมาเล่นได้ทันทีโดยไม่ต้องตั้งค่าอะไร สิ่งที่สคริปต์ตั้งไว้คือ

- เปิดคาบของห้องแล้ว
- ช่วงของคาบ = **ภารกิจย่อย** ตั้งนาฬิกา 20 นาที
- แบบทดสอบก่อนเรียน = **เปิด**
- ผนังผลงานของเพื่อน = **เปิด**

อยากลองกดเองก็ได้ ทุกปุ่มอยู่ที่ http://localhost:3000/teacher

| อยากทำอะไร | กดที่ไหน |
|---|---|
| ย้ายช่วงของคาบทั้งห้อง | กล่อง **ช่วงของคาบ** → แถวปุ่ม `รอเริ่ม / รู้จักตัวเอง / ภารกิจย่อย / ด่านบอส / ครูสรุป / สะท้อนคิด / จบคาบ / ทำต่อที่บ้าน` |
| กดพลาดอยากย้อน | ปุ่ม **ย้อนการย้ายช่วง** (ใช้ได้ภายใน 30 วินาที) |
| เพิ่มเวลา / หยุดนาฬิกา | ปุ่ม `+1 / +3 / +5 นาที` และ `หยุด` ในกล่องเดียวกัน |
| เปิด-ปิดแบบทดสอบก่อนเรียนหรือหลังเรียน | กล่องแบบทดสอบท้ายหน้า (**ไม่ทำให้ทั้งห้องเด้งไปช่วงอื่น**) |
| ให้ทุกคนหยุดมองจอหน้าห้อง | ปุ่ม **ให้ทุกคนดูจอหน้าห้อง** |
| ยกงานของเด็กขึ้นจอหน้าห้อง | กล่องปักหมุดผลงาน |
| **ตอบคำขอของเด็ก** (ขอลดความยาก ขอเปลี่ยนวิธีเรียน ขอข้ามด่าน ขอเวลาเพิ่ม) | ไปที่ **แผงห้องเรียนสด** http://localhost:3000/teacher/board · กล่อง **คำขอเปลี่ยนแผนจากผู้เรียน** อยู่บนสุด บอกว่ารอตอบกี่ใบและรอมานานเท่าไร · ตอบได้ 3 ปุ่ม **ครูให้ตามที่ขอ** / **ครูให้แบบอื่นแทน** / **ครูยังไม่ให้รอบนี้** พร้อมพิมพ์ข้อความสั้น ๆ ตอบกลับเด็กได้ |

ลำดับที่ใช้จริงในคาบ 60 นาที: `รอเริ่ม` → เปิดแบบทดสอบก่อนเรียน → `รู้จักตัวเอง` → `ภารกิจย่อย` → `ด่านบอส` → `ครูสรุป` → `สะท้อนคิด` → เปิดแบบทดสอบหลังเรียน → `จบคาบ`

## 7. จะดูผลตรงไหน

| อยากดู | ดูที่ |
|---|---|
| ใครติด ใครขอครู | http://localhost:3000/teacher กล่อง **ธงจากความมั่นใจของผู้เรียน** (ตอนนี้มี 5 การ์ด — ควรคุย 2 · ควรชม 3) |
| งานที่รอตรวจ + กดยืนยันคะแนน | หน้าเดียวกัน หัวข้อ **งานที่รอตรวจ** (ตอนนี้มีของฟ้าใส 1 ใบ) · ในใบมีปุ่มยืนยันคะแนนและปุ่มส่งกลับให้แก้ |
| ข้อความที่ต้องดูแล | กล่องบนสุดของหน้าครู (ว่างอยู่ = ไม่มีคำไม่เหมาะสม ถูกต้องแล้ว) |
| ภาพรวมสด ๆ ขึ้นจอโปรเจกเตอร์ | http://localhost:3000/board — รหัสห้อง QR นาฬิกา เข้ามาแล้วกี่คน ผ่านไปกี่ภารกิจ ส่งงานแล้วกี่ชิ้น และผลงานที่ครูปักหมุด |
| ผนังผลงานเพื่อน (มุมนักเรียน) | เข้าเป็นนักเรียนแล้วไปหน้า **ผลงานของเพื่อน** (`/showcase`) · ในห้องมีผลงานทั้งหมด 3 ชิ้น แต่หน้านี้**ตัดงานของตัวเองออก** จึงเห็น 2 ชิ้น (งานตัวเองไปดูที่หน้าผลของฉัน) |
| **ห้องกำลังเป็นอย่างไรตอนนี้** ใครต้องช่วยก่อน | http://localhost:3000/teacher/board — เรียงคนที่ต้องช่วยขึ้นก่อนเสมอ มีตัวเลขบนหัว: อยู่ในห้องกี่คน · กดขอครูกี่คน · ติดธงเตือนกี่คน · งานรอตรวจกี่ใบ · หน้านี้อัปเดตเองทุก 3 วินาที ไม่ต้องกดโหลดใหม่ |
| **ตัวเลขของทั้งห้อง** สำหรับเอาไปใส่สไลด์กับเอกสาร | http://localhost:3000/teacher/report — มีค่าประสิทธิภาพสื่อ (E1/E2) เทียบเกณฑ์ 80/80 · ปุ่ม **ดาวน์โหลด CSV** เปิดด้วย Excel ได้เลย · ปุ่ม **พิมพ์ / บันทึกเป็น PDF** · ปุ่ม **คัดลอกตัวเลขทั้งชุด** |
| **รายงานของเด็กคนเดียว** | http://localhost:3000/teacher/student — กดชื่อเด็กจากแถวบน แล้วดูของคนนั้น มีปุ่มพิมพ์เป็น PDF ให้แนบแฟ้มรายบุคคล |

ไฟล์ CSV ที่ปุ่มนั้นโหลดให้ **ตัดชื่อเล่นออกให้แล้ว** เหลือแค่รหัส S01 S02 … เอาไปแนบเอกสารได้โดยไม่ต้องกังวลเรื่องข้อมูลเด็ก

หน้ารายงานห้อง `/teacher/report` มีตัวเลขจริงให้ดูครบแล้ว ไม่ใช่ขีดกลาง — หุ่นทั้ง 6 คนมีคะแนนก่อนเรียนและหลังเรียนติดมาให้ตั้งแต่ seed (E1/E2 = 33.95/76.67 · t = 4.715, df = 5, p = 0.0053 · Cohen d = 1.92 · Hedges g = 1.62 · ค่าความยากกับอำนาจจำแนกแยกชุด A/B · ร้อยละความตรงกัน 75%)

> **ตัวเลขบนสองหน้านี้วัดคนละอย่าง อย่าตกใจถ้าไม่เท่ากัน**
> กล่อง **ธงจากความมั่นใจของผู้เรียน** บนหน้า `/teacher` นับจาก "เด็กบอกว่ามั่นใจแค่ไหน เทียบกับผลจริง" — ตอนนี้มี **5 การ์ด** (ควรคุย 2 คือ มะลิ กับ ปูเป้ · ควรชม 3 คือ ต้นกล้า ปูเป้ บีม)
> ตัวนับ **ควรคุย (ความมั่นใจ)** บนแผงห้องเรียนสดเป็นอีกเกณฑ์หนึ่ง นับเฉพาะภารกิจที่เด็กกำลังทำอยู่ตอนนี้ จึงขึ้น 0 ได้เป็นเรื่องปกติ
> ส่วน **ติดธงเตือน 2 คน** บนแผงห้องเรียนสดมาจากอีกเกณฑ์ (ค้างนานเกินไป ตอบผิดซ้ำ กดขอครู) คนละตัวกับสองอันข้างบน

## 8. อยากล้างแล้วเริ่มใหม่

```bash
npm run seed:uat
```

สั่งซ้ำได้ตลอด ไม่ต้องปิด dev server สคริปต์จะ

- **ลบเฉพาะห้อง `UAT777` ของครู `kru@uat.local`** แล้วสร้างใหม่ทั้งห้อง
- ไม่แตะห้องอื่นแม้แต่ห้องเดียว (ห้องเดโม `QUEST9` ของ `scripts/seed-demo.ts` อยู่ครบ)
- ถ้ารหัส `UAT777` ดันกลายเป็นของครูคนอื่น สคริปต์จะหยุดและไม่ลบอะไรเลย

ผลข้างเคียงที่ต้องรู้: ทุกอย่างที่เล่นไว้ในห้อง UAT777 หายหมด **รวมถึงที่นั่งของตัวเองด้วย**
เข้าใหม่ได้เลย ใช้ชื่อเล่นเดิมกับรหัส 4 หลักเดิมได้ไม่ติดอะไร

## 9. คืนนี้เพิ่มอะไรมาให้ลองเล่น

เขียนแบบเล่าให้ฟัง ทุกอย่างในนี้ลองกดได้จริงในห้อง `UAT777` เดี๋ยวนี้

**ฝั่งครู — ได้จออีก 3 จอ เมื่อก่อนมีแต่หลังบ้าน กดดูไม่ได้**

1. **แผงห้องเรียนสด** เห็นเด็กทุกคนในหน้าเดียว เรียงคนที่ต้องเข้าไปช่วยขึ้นก่อน ไม่ต้องไล่หาเอง
   หัวจอบอกทันทีว่าอยู่ในห้องกี่คน ใครกดขอครูบ้าง ติดธงเตือนกี่คน งานค้างรอตรวจกี่ใบ
   จอนี้ขยับเองทุก 3 วินาที วางไว้ข้างจอสอนได้เลย
2. **รายงานรายห้อง** ตัวเลขทั้งห้องรวบมาให้แล้ว รวมค่าประสิทธิภาพสื่อที่ต้องใช้ในเอกสารส่งประกวด
   มีปุ่มโหลดเป็นไฟล์ตารางเปิดด้วย Excel และปุ่มพิมพ์เป็น PDF
3. **รายงานรายคน** กดชื่อเด็กคนเดียวแล้วดูของเขาคนเดียว พิมพ์แจกผู้ปกครองหรือแนบแฟ้มได้

**เด็กขออะไรได้เอง แล้วครูกดตอบบนจอ**
เมื่อก่อนเด็กอยากลดความยากหรือขอเวลาเพิ่มต้องยกมือเรียกครูแล้วครูจดเอง
ตอนนี้เด็กกดขอจากในหน้าภารกิจได้เลย 4 แบบ คือ ขอลดความยาก · ขอเปลี่ยนวิธีเรียน · ขอข้ามด่านนี้ · ขอเวลาเพิ่ม
คำขอไปโผล่บนแผงห้องเรียนสดทันที บอกด้วยว่ารอมานานแค่ไหน ครูกดได้ 3 ทาง
**ให้ตามที่ขอ** / **ให้แบบอื่นแทน** / **ยังไม่ให้รอบนี้** และพิมพ์เหตุผลสั้น ๆ กลับไปให้เด็กอ่านได้

**เด็กขอเพื่อนช่วยได้**
ในหน้าภารกิจมีปุ่มขอเพื่อนช่วย ถ้ามีเพื่อนในห้องที่ว่างและทำด่านนั้นผ่านแล้ว ระบบจะชวนเขามาช่วย
ถ้าไม่มีใครว่าง เด็กจะได้การ์ดคำถามให้ลองคิดเองก่อน แล้วค่อยกดเรียกครู — ไม่ปล่อยให้นั่งตันเฉย ๆ

**เช็กชื่อเว็บก่อนยื่นได้**
ที่หน้ายื่นป้ายร้าน พิมพ์ชื่อที่อยากได้แล้วระบบบอกว่าชื่อนี้ถูกคนอื่นจดไปแล้วหรือยังว่าง
ถ้าไม่ว่างก็เสนอชื่อใกล้เคียงมาให้เลือก 3 ชื่อ พร้อมบอกว่าชื่อที่พิมพ์ผ่านกฎการตั้งชื่อครบไหม (ความยาว ตัวอักษรที่ใช้ อ่านออกเสียงได้ไหม)

> อยากดูของพวกนี้แบบมีข้อมูลอยู่แล้ว ไม่ต้องเล่นเองตั้งแต่ต้น ให้เข้าเป็นครูแล้วเปิดแผงห้องเรียนสด — หุ่น 6 คนในห้องมีสถานะครบทุกแบบให้ดูอยู่แล้ว
