# แผนงานภาพ isometric 2D — และวิธีแก้ปัญหา "เล่นยาก"

บันทึกเมื่อ 29 กันยายน 2569

---

## 1. ข้อสังเกตที่ถูกต้องมาก

> **"ทำแบบ isometric 2D มันก็เล่นได้ยากนะ"**

ใช่ ถ้าใช้ isometric เป็น **สนามที่ต้องเดิน** จะเจอปัญหาทุกข้อนี้

| ปัญหา | เกิดจาก |
|---|---|
| ทิศทางสับสน | กดลูกศรขึ้น ตัวละครเดินเฉียงขึ้นขวา ไม่ตรงกับที่นิ้วสั่ง |
| แตะพลาดบนมือถือ | ช่องกระเบื้องเป็นสี่เหลี่ยมขนมเปียกปูน พื้นที่แตะจริงเล็กกว่าที่ตาเห็น |
| วัตถุบังกัน | ต้องเขียนโค้ดจัดลำดับการวาดตามความลึก ผิดนิดเดียวตัวละครมุดเข้ากำแพง |
| เสียเวลาเดิน | นักเรียนใช้เวลาไปกับการเดินหาสถานี แทนที่จะได้เรียน — ในคาบที่มีแค่ 20 นาทีคือหายนะ |

**แต่เกมของเราไม่ต้องเดินเลย**

---

## 2. ทางออก — isometric เป็น "ภาพ" ไม่ใช่ "สนาม"

```
หน้าแผนที่ (isometric)          หน้าเล่นจริง (2D ตรง ๆ)
┌───────────────────────┐       ┌───────────────────────┐
│   🏗️ ร้านของฉัน       │       │  โรงทำป้าย            │
│                       │  แตะ  │  [สายพานตัวอักษร]     │
│  🏠A  🏢B  🎪C  📚    │  ───▶ │  [ป้ายร้าน + มาตรวัด] │
│   ↑ แตะที่อาคาร       │       │  [ช่องพิมพ์]          │
└───────────────────────┘       └───────────────────────┘
   ดูอย่างเดียว                    เล่นจริงตรงนี้
   ไม่มีการเดิน                    ปุ่มใหญ่ แตะง่าย
```

**กฎ 3 ข้อ**
1. หน้าแผนที่ isometric **แตะได้แค่ 5 จุด** (อาคาร A/B/C + ห้องสมุด + เวทีเปิดร้าน) ไม่มีตัวละครให้บังคับ ไม่มีการเดิน
2. พื้นที่แตะเป็นสี่เหลี่ยมมุมฉากธรรมดาวางทับภาพ ไม่ต้องคำนวณพิกัด isometric
3. พอแตะแล้ว **ซูมเข้าไปหน้าเล่นแบบ 2D ตรง ๆ** ปุ่มใหญ่ ฟอร์มปกติ แตะง่ายบนมือถือ

ผลที่ได้: ได้ความสวยของ isometric โดยไม่ต้องรับปัญหาการควบคุมเลยสักข้อ
เขียนโค้ดก็ง่ายกว่ามาก — แผนที่คือรูป PNG หนึ่งใบ + ปุ่มโปร่งใสวางทับ

---

## 3. เรื่องลิขสิทธิ์ — พูดครั้งเดียว

"ใช้เพื่อการศึกษา" ไม่ได้แปลว่าใช้ภาพมีลิขสิทธิ์ได้อัตโนมัติ และงานนี้จะเอาไป **แข่ง** กับขึ้นเว็บสาธารณะ ซึ่งเกินขอบเขตการใช้ในห้องเรียน
ประเด็นจริงคือ **ไม่มีเหตุผลต้องเสี่ยงเลย** เพราะของฟรีที่ใช้ได้ถูกกฎหมายมีเยอะและคุณภาพดีพอ ๆ กัน แถมยังเขียนลงสไลด์ได้ว่า "ใช้ทรัพยากรที่มีสัญญาอนุญาตถูกต้อง" ซึ่งเป็นแต้มบวกในหัวข้อ *วิธีการสร้างสื่อและเครื่องมือที่ใช้* (20 คะแนน)

ถ้าสุดท้ายทีมตัดสินใจใช้ภาพจากที่อื่นอยู่ดี ก็เป็นการตัดสินใจของทีม — แต่ให้เก็บลิงก์ต้นทางไว้ทุกภาพ เผื่อกรรมการถาม

## 6. ข้อที่สำคัญกว่าเรื่องภาพ

**หน้าแผนที่กินเวลาเล่นแค่ประมาณ 5%** นักเรียนอยู่ในสถานี A/B/C ราว 90% ของคาบ

- อย่าทุ่มหลายวันกับแผนที่
- ถ้าเวลาบีบ ทำเป็น **การ์ด 5 ใบวางเรียง** มีไอคอนกับกุญแจล็อกก็พอ — เล่นได้เหมือนกัน เดโมได้เหมือนกัน
- ค่อยอัปเป็น isometric ทีหลังถ้าเหลือเวลา

ความว้าวตอนนำเสนอมาจาก **ฉากเปิดร้าน + ใบประกาศ** ไม่ใช่แผนที่
