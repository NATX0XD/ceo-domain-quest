# CEO Domain Quest

เรื่อง **โดเมนเนม** · วิชา **21910-2002 อินเทอร์เน็ตในงานธุรกิจดิจิทัล** (ปวช. 2567) · ปวช.1 · 1 คาบ 60 นาที

> ทุกคนผ่านด่านเดียวกันไปสู่เป้าหมายเดียวกัน แต่ได้โจทย์ ระดับ และตัวช่วยที่เหมาะกับตัวเอง

## รันโปรเจกต์

```bash
npm install
npm run db:start                         # Supabase local (ห้ามรัน db reset ระหว่างมีคนทดสอบ)
npm run seed:uat                         # ห้องสำหรับลองเล่น (UAT777)
npx tsx scripts/seed-demo.ts             # ห้องสาธิตวันแข่ง 20 คน
npm run dev
npx vitest run                           # เทสต์ตรรกะ ไม่ต้องใช้ฐานข้อมูล
npx tsc --noEmit --incremental false     # typecheck (อย่าใช้ npm run typecheck มี cache หลอก)
npm run check:wired                      # หาโค้ดที่เขียนเสร็จแต่ไม่มีใครเรียก
npm run check:leaks                      # กันเฉลย/ของลับหลุดถึงเบราว์เซอร์
npm run check:authz                      # ตรวจสิทธิ์เข้าถึง
npx tsx scripts/check-deploy.ts          # ตรวจความพร้อมก่อน deploy
npx tsx scripts/load-test.ts             # จำลอง 30 คนพร้อมกัน
npx tsx scripts/capture-screenshots.ts   # เก็บภาพหน้าจอสำหรับสไลด์
```

**สำคัญกับวันสอน:** คิวตรวจงานด้วย AI เดินก็ต่อเมื่อครูเปิดแผงครูค้างไว้ ไม่มีตัวรันอัตโนมัติ
ทางสำรอง `npx tsx scripts/grade-worker.ts --watch`

## ตัวเลขที่วัดจริงแล้ว

- **30 คนพร้อมกัน 275 คำขอ พลาด 0.00% ไม่มี 500** · เข้าห้อง p50 184ms · ส่งด่านบอส p50 208ms (ไม่มีใครรอ AI)
- คิวตรวจครบ 30 ใบใน **2 นาที 45 วินาที** · แผงครู poll ค้างไว้ p50 32ms · ที่ห้อง 220 คนยังตอบ 27ms
- คำใบ้ไม่เกินงบ 5 วินาทีทุกครั้ง · ปิด AI แล้วตกกฎใน 30ms · ถอดคีย์แล้วเดินจบได้ใน 1ms
- โครงหน้าจอ 100dvh ไม่เลื่อนทั้งหน้า วัด **69/69 ผ่าน** ที่ 390/768/1280
- ความปลอดภัย: เฉลยหลุด 0 · ของลับหลุด 0 (3,437 ไฟล์) · สวมรอย 26/27 · ลบห้องแล้วข้อมูลหายจริง
- สถิติจากห้องจริง: E1/E2 33.95/76.67 · t 4.715 df 5 p 0.005266 · Cohen d 1.9249 · Hedges g 1.621 · ค่าความยาก/อำนาจจำแนกครบ 2 ชุด

> ตัวเลขโหลดวัดบนเครื่องพัฒนา ยังไม่ได้วัดบน production กับเน็ตโรงเรียนจริง และวัดเฉพาะฝั่ง API
> ตัวเลขสถิติมาจากห้องหุ่น ใช้พิสูจน์ว่าระบบคำนวณถูก **ไม่ใช่ผลทดลองจริง**

## โครงไฟล์

```
core/           ตรรกะล้วน ไม่ import React/Next/DB
content/        เนื้อหา JSON ทีมแก้เองได้ · เฉลยอยู่ใน *-answers.json เท่านั้น
lib/ai/         ลูกโซ่ผู้ให้บริการ + ทางสำรองแบบกฎ + คิวเบื้องหลัง + สวิตช์ปิด AI
lib/db/         repo วิ่ง service_role ข้าม RLS — ตรวจสิทธิ์ในชั้นนี้เอง
app/            หน้าเว็บ + API route (app/teacher = ฝั่งครู)
postman/        collection ยิงทดสอบ รวมโฟลเดอร์ "ทดสอบว่าโกงไม่ได้"
docs/           เอกสารออกแบบ แผนการสอน คู่มือครู สไลด์ คำถามกรรมการ ภาพหน้าจอ
```
